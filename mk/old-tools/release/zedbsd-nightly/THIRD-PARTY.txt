zedbsd-nightly: third-party software
====================================

This package bundles the programs and libraries below. Each keeps its own
license; the full texts are in the LICENSES directory (LICENSES/<name>/).
Where a license (GPL, LGPL) requires the corresponding source code, the
"Source" line says where to get the exact source of the bundled binary.

The disk image (data/hdd-image.img, when present) is zedBSD, distributed
under the zlib license: https://github.com/awemorris/zedBSD. The licenses of the
software inside the image are installed in the image under /usr/share/licenses.


QEMU emulator (WINQ-EMU fork)
-----------------------------

Files:   qemu-system-x86_64.exe, qemu-img.exe,
         share/keymaps/*, share/firmware/*.json,
         share/kvmvapic.bin, share/linuxboot_dma.bin, share/multiboot_dma.bin,
         share/pvh.bin, share/vof.bin, share/vof-nvram.bin
Version: QEMU 11.0.0 with the WINQ-EMU alpha10 patches (WHPX, Venus on
         Windows) and changes for zedBSD
License: GPL-2.0-only; some parts are under other GPL-compatible licenses
         (LICENSES/qemu/LICENSE explains which)
Source:  https://github.com/awemorris/qemu-win32-vulkan
         commit @QEMU_COMMIT@
         (fork of https://github.com/cmspam/winq-emu-qemu, branch alpha10,
         which is based on https://download.qemu.org/qemu-11.0.0.tar.xz)
Built:   MSYS2 UCRT64 (qemu-system-x86_64.exe with GCC 16.2.0,
         qemu-img.exe with GCC 15.2.0)
