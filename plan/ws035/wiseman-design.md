# Wiseman: zdesktop のウィンドウマネージャの操作体系（ユーザーの設計、2026-09-26）

2026-09-26 にユーザーが示した設計の記録。実装は疎通確認の Phase（p059 から）で段階的に進める。
[compositing-design.md](compositing-design.md) の D7（装飾）の改訂は p025 でまとめる（承認待ち）。

## 名前

- ウィンドウマネージャは **Wiseman**（WM にかけて）。
- 全画面モード（design D0 の直接 scanout）は **ゲームモード**、ウィンドウモードは **Wiseman Mode**。
- ウィンドウ一覧（Mac の Exposé 相当）は **Wiseview**（Exposé の名は使わない）。

## 操作の 3 つの方向

「上はウィンドウを掴む。下はウィンドウ群を見る。左右は空間を移動する。」

| 操作 | 意味 |
| --- | --- |
| 上部の合体タイトルバー（ドッキング中）を下へ | 最大化の解除。10〜20 px 引くと窓の上端が画面から離れ、さらに引くと左右にも余白、角丸と影が戻る。閾値を越えたら通常の大きさへ snap、届かなければバネで最大化へ戻る。途中で上へ戻したら最大化に戻る |
| 画面の下端から上へ | Wiseview |
| 画面の左端・右端から内側へ | 前・次の仮想デスクトップ。画面が指に追従して横へずれ、隣が覗く。端から 12〜16 px 以内で始めたときだけ OS が取り、中央の横スワイプはアプリへ |
| タッチパッド | 3 本指左右 = 仮想デスクトップ、3 本指上 = Wiseview、ドッキング中のタイトルを 1 本指で下 = 解除 |

- 全部を物理的な移動として一貫させる（フェードやページ切替を混ぜない）。追従は指に 1:1、離した後 150〜220 ms で決着、慣性と弾みは弱め。
- 判定は距離と速度: 仮想デスクトップは画面幅の 25〜30 % 未満なら戻る、速ければ短くても切り替える。

## Wiseview

目的の優先順位: 見つけやすさ、現在地のわかりやすさ、戻りやすさ、美しさ。

- **2 段階**: Peek（軽く引く: 今の窓が縮み、背景が少し暗く、他の窓がうっすら）→ Active（閾値を越える: 全窓がタイルに並び、選択・drag ができる）。
- **画面の zone**: A 上部のバー（そのまま。ドッキング中の題名は「Wiseview」等に置き換えるか消す。少し不透明に。仮想デスクトップ列を強調）、B 任意の説明帯（「このデスクトップのウィンドウ」「5 windows」）、C 一覧（左右 48〜72 px、上下 32〜48 px、ガター 20〜28 px）、D 下の補助（下スワイプで閉じる、ヒントは初回だけ）。
- **並び**: 重ならない、同じくらいの大きさ、元の縦横比、左上から右下。順は今の窓、使った順（MRU）、同じアプリは続けて。
- **列数**: 1 枚は中央に大きく、2 枚は 2 列、3〜4 枚は 2×2、5〜6 枚は 3×2、7〜9 枚は 3×3、10〜12 枚は 4 列、13 枚以上は 4〜5 列で縮みすぎれば縦スクロール。
- **タイルの大きさ**: 最小 220×140（実装の目安 240）、快適 280〜420、最大は画面幅の 42 %・高さの 36 %。
- **タイルの中身**: プレビュー（角丸 14〜18、縦横比維持、影は弱め、選択候補だけ青い glow）、タイルの下の外に題名（アプリの印と題名、1 行で省略）、hover で右上に閉じる。最小化・最大化・menu は出さない。状態の badge はごく控えめに。
- **背景**: 今のデスクトップの背景を中程度にぼかし、明るさを 8〜15 % 落とし、彩度を少し下げる（黒で覆わない）。
- **今の窓**: 1.03〜1.06 倍、題名を濃く、薄い accent。
- **仮想デスクトップ**: 一覧は今のデスクトップの窓だけ。上部の仮想デスクトップ列を強調し、タイルをそこへ drag で移動、左右スワイプで一覧ごと隣のデスクトップの Wiseview へ横に移る。
- **遷移**: 入口は最大化の窓が 100→92→84 % と縮み、背景のぼかしが増え、他のタイルが下・奥から現れて整列（追従は 1:1、離した後 180〜240 ms）。選択はタイルが前に出て他が消え、その窓が戻る（ドッキング中ならタイトルが再びバーへ）。キャンセルは今の窓が戻る。
- **入力**: click で選択、背景の click・下へのスワイプで閉じる、Esc で閉じる、Tab・矢印・Enter、Ctrl+←/→ でデスクトップ。
- **特殊**: 窓 1 枚でも大きく見せて「他のウィンドウはありません」、最小化の窓は既定で含めない、ダイアログは親と 1 枚、同じアプリは並べる。
- 実装の初めの目安: 左右 56・上下 40・ガター 24、3 列を基本に 2・4 列、最小幅 240、背景のぼかしと黒 8 %、角丸 16、題名は下に 1 行、今の窓は 1.04 倍と薄い青の glow、下から 20 px 内で始めた上スワイプで起動、左右は端から 16 px。

## 最大化 = ドッキング（p062 で疎通）

浮いたタイトルバーのダブルクリック・上への drag で窓が上部のバーにドッキングし、題名がバーの左へ入る（`[印] zedBSD │ [W] 題名 … — ⧉ × │ 仮想デスクトップ │ 通知領域`）。発展: 題名の click でアプリの menu、右 click で窓の menu。
