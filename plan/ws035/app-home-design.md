# App Home: zdesktop のアプリのホーム画面（ユーザーの設計、2026-09-26）

2026-09-26 にユーザーが示した仕様の記録。名前は仮に **App Home**（見た目は Home）。実装は PoC（ws035-p070）から段階的に進める。
操作体系の全体は [wiseman-design.md](wiseman-design.md)。

## 空間モデル

zedBSD の画面は「空間を直接動かす」操作で統一する。

| 層 | 意味 | 操作 |
| --- | --- | --- |
| Desktop | 作業する場所 | — |
| Wiseview | いま開いている窓を俯瞰する | 下から上 |
| 仮想デスクトップ | 作業空間を移る | 左右 |
| App Home | 次に開くアプリを選ぶ | 左上から右下（デスクトップをめくる） |
| （最大化の解除） | ドッキングした窓を引き剥がす | 上から下 |

App Home は暗いオーバーレイ（GNOME の Overview）でなく、明るいホーム画面そのもの。
今の作業空間（上層）が右下へ退避し、その下から App Home（下層）が現れる。フェードで切り替えず、レイヤーを物理的にずらす（紙を斜めにずらして下の層を見る）。

## 開く・閉じる

- 開く: 上部バー左上の zedBSD アイコンのクリック、または画面の左上端から右下へのスワイプ。クリックでも同じ方向の動き（左上から Home が現れ、デスクトップが右下へ押し出される）。
- 閉じる: zedBSD アイコンの再クリック、右下に残ったデスクトップの端のクリック、右下から左上へのスワイプ、Esc、アプリの起動。開くときと完全に逆の動き。
- 退避したデスクトップは完全には消さない: 右端 8〜12 px、下端 8〜12 px、右下の角 16〜24 px（角丸がわかる程度）が残り、壁紙・窓の端・影が見える。その端は戻る操作の対象（マウスが近づくと少し広がってもよい）。
- ジェスチャーの判定: 左上から始めたものだけ（X < 24 px かつ Y < 24 px、または角から半径 32 px）。方向は dx > 0 かつ dy > 0 で一定以上の移動（45° ちょうどは求めない）。12〜20 px を越えるまで確定しない。短いタップはアイコンの操作。
- ジェスチャー中の進み p（0〜1）: デスクトップの offset = p × 目標、縮小は 1.0 → 0.97 程度（スライドが主、縮小は補助）、Home の不透明度 0 → 1、Home のぼかし 大 → 0。指に 1:1 で追従。
- 時間: クリックで開く 260〜320 ms、閉じる 220〜280 ms。スワイプは離してから 160〜220 ms。ページ送り 180〜220 ms。検索の開始 120〜160 ms。

## 見た目

- 背景は暗くしない。白〜淡い青、今の壁紙を大きくぼかし彩度とコントラストを少し落としたもの、軽いすりガラス。アイコンより主張しない。
- 上部のシステムバーは残す。左は `[zedBSD アイコン] zedBSD`（アイコンは「ホーム状態」で少し強調）、窓の題名は消す。右（仮想デスクトップ・ネットワーク・電池・時計・通知）はそのまま。
- 避けるもの: 黒いオーバーレイ、巨大な検索バー、左のランチャーバー、細かいカテゴリ一覧、窓の縮小表示、過剰な情報。
- 欲しいもの: 大きなアイコン、広い余白、明るい背景、ページ単位の移動、直接的なジェスチャー、静かな検索。

## アイコンの格子

- 均等グリッド。基準は 6 列 × 4 行 = 24 アプリ / ページ。高解像度でも列を増やしすぎず余白を優先。
- 各セル: アイコン（64〜72 px）、アプリ名（13〜15 px、1 行）、任意の通知バッジ。カテゴリの見出しや説明は出さない。セル幅 120〜150 px、行間 36〜52 px。
- 並び: 最初は自動配置（よく使う・固定・その他）、以後はユーザーが決めた位置を保つ。並べ替え（長押し・Alt+drag・context menu）は将来。

## ページング

- 1 ページに収まらなければ横ページング（Home の中では左右スワイプ = ページ、仮想デスクトップではない）。
- ドラッグ中は 1:1、離すと 180〜220 ms でページへスナップ（途中で止まらない）。判定は距離と速度: 画面幅の 25 % 以上、または十分な速度で次のページ、それ以外は戻る。
- 画面下中央に控えめなドット（`● ○ ○ ○`、今のページだけアクセント色）。1 ページなら出さない。
- 最後に見ていたページを保つ（少なくともセッション中）。

## 検索

- 検索欄は出さない。Home の表示中に文字を打った瞬間に検索モードへ。
- 上部中央に入力した文字列だけを浮かべる（必要ならごく薄い半透明のピル）。
- 検索中はページングを止め、結果を 1 つの連続した格子に。結果が少なければ（1〜6 件）中央寄せ。背景や配置は変えず、アイコンが滑らかに再配置される。
- 対象: アプリ名、実行ファイル名、キーワード・カテゴリ（`term` → Terminal、`web` → Browser）。
- 解除: Esc、Backspace で空、Home を閉じる、アプリの起動。解除後は検索前のページへ。

## 起動

- アイコンを押すと: アイコンが少し拡大、Home が左上へ退き、右下に退避したデスクトップが戻り、新しい窓がその位置から生まれるように現れる。
- 既に窓があるアプリは、新規起動でなくその窓を前面に出してもよい（single-instance の属性と連携）。

## キーボードとマウス

- キーボード: 文字 → 検索、Esc → 戻る、← → → ページ、矢印 → アイコンの選択、Enter → 起動、Tab → 次のアイコン。検索中は矢印で結果を選ぶ。
- マウス: クリックで起動、ホイール（任意）・Shift+ホイールでページ。初期実装はクリックとページ送りで十分。

## 仮想デスクトップとの関係

- Home の中では左右スワイプはページ送り。上部バーの仮想デスクトップの button は操作できる。
- Home の表示中に仮想デスクトップを切り替えても Home は閉じず、背後に退避したデスクトップだけが変わる。閉じるとそのデスクトップへ戻る。
