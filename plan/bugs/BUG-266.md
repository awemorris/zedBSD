# BUG-266: 拡張で eDP を off にすると Wayland の session が落ちる（USB-C の DP に 1 出力で移す時に失敗）

- 状態: reproduced（実機 5330、2026-10-08 午後 ユーザーの UAT） / scheduled
- 由来: ユーザー「拡張モードで、eDPをオフにする操作をしたところ、Waylandセッションが落ちました。SSHでログを見てください。」「eDPをオフにするとWaylandが落ちる問題をまず解決しましょう。そのあとマルチタッチ。」
- 同じ UAT で: USB-C の DP（TC2）の出力・拡張・mirror は動いた（BUG-256 の直しが効いた）。
- kernel: main 932b07bb4 の build（Q1 が 5330 に入れた vmunix cksum 567766690、wayland 2020052779、libkeiland 3875603912、settings 552170007）。
- 証拠: [BUG-266/](BUG-266/) の kernel.log・session.log（compositor）・sessiond.log・messages・greeter.log・displays.conf。

## 観察（Q1）

- displays.conf: `mode=extended`、`anchor=…dp:TC2`、`off=…edp:A`。
- session.log の最後: `KWL OUTPUT display index=0 …dp:TC2 shown=1`、`index=1 …edp:A shown=0` → `KWL VULKAN_ERROR operation=submit result=-4`（DEVICE_LOST）→ `KWL FAILED site=compose_draw errno=5` → clients の cleanup → `KWL EXIT … error=5 cleanup_failed=1`。sessiond は `SESSION end … status=256` で greeter に戻った。
- kernel.log（4128 行の前後）: eDP を off にして DP だけにする時、resident display を TC2 に移す経路（ws113-p011a の 1 出力の付け替え）が `resident display: ended FAIL (show rc=5; … first anomaly: WARN_ON(!intel_tc_port_in_legacy_mode(dig_port)))` → `resident display: the moved output failed; the firmware's output (eDP panel) is the output again, and the lease's presentations fail until the next claim`。同じ行が 1955・2873 行にもある（3 回）。
- → 2 つの欠け（Q1 の見立て）: (1) i915 の 1 出力の付け替えが TC の port を legacy の mode と仮定していて、DP-alt の port で失敗する。(2) 付け替えが失敗した時、compositor が present の失敗を DEVICE_LOST として受けて session ごと終わる（eDP に戻して続けるべき）。
