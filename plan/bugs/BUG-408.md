# BUG-408: ブラウザ: Google の検索の結果の頁が JavaScript の確認（BotGuard）を通らず reCAPTCHA の頁になる

- 状態: open（2026-11-02 10:40 P8 が起票、Q1 の指示。この Queue（q1924）では直さない）
- 発見: 2026-11-02 P8（BUG-407 の確かめの中）。
- 中身: BUG-407 の直しで「Google 検索」「AI モード」・Enter が `/search?q=…` へ遷移するようになったが、`/search` は結果の代わりに Google の JavaScript の確認の頁を返す。頁の script が `/js/bg/` の script（BotGuard）を後から読み、`solveSimpleChallenge` を呼ぶが、こちらでは `Uncaught ReferenceError: solveSimpleChallenge is not defined` になり、確認が通らないので頁の script が `/sorry/index`（reCAPTCHA、「お使いのコンピュータ ネットワークから通常と異なるトラフィックが検出されました」）へ遷移する。sorry の頁では `Worker is not defined`（Web Worker が無い）も出る。
- 再現（Linux の host build、`build/tmp/p8u/drive.c` の道具）: `https://www.google.com/search?q=zedbsd` を開くと、確認の頁の後に `/sorry/index?continue=…` が commit される。BUG-407 の直しの前は script の top-level の遷移が無かったので、確認の頁のまま止まっていた（結果は出ない）。
- 見込み（未確認）: BotGuard の script が読めない（後から足す script の取得・実行、または使う API の欠け）。結果の頁を出すには BotGuard が動く必要がある。
- 扱い: 未定（Q1）。
