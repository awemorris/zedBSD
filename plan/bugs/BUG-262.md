# BUG-262: アクセントカラーを既定（青）に戻しても desktop の Files（icon の選択の色）が追従しない疑い

- 状態: reproduced（QEMU、T1-396 の log） / scheduled（2026-10-08 夜 P2 q878 で原因を特定し修正、T1 の再試験待ち）
- 発見: 2026-10-08 T1-396（desktop.appearance.accent）の Q1 の判定。
- 観察: Purple を選ぶと `ZSETTINGS ACCENT index=1`・`KWL THEME ... accent=1`・`ZFILES ACCENT index=1` が出る。Blue に戻すと `ZSETTINGS ACCENT index=0`・`KWL THEME ... accent=0` は出るが、`ZFILES ACCENT` の行が出ない（record の step 9）。userland/desktop/files/main.c の main_desktop_accent_changed は呼ばれれば必ず log を出すので、watch が来ていない。Settings・system bar の色は青に戻る（PNG build/review/t1-39x/desktop.appearance.accent-blue.png）。
- 推定（未確認）: Settings は既定を選ぶと key を消す（設定を既定に戻す）、kl_settings_watch が key の削除で callback を呼ばない。
- 影響: desktop の icon の選択の pill などが前の accent のまま残る。

## 次

- Settings の accent の書き方（既定で key を消すか）と libkeiland の kl_settings_watch の削除の扱いを読み、host で再現して直す（削除でも callback を呼ぶか、Settings が既定でも値を書く）。AAT desktop.appearance.accent の step 9 で ZFILES ACCENT index=0 を必須にする。

## 原因（2026-10-08 夜、P2 q878、T1-396 の生の log で確定）

watch は来ていた。T1 の `logs/desktop.appearance.accent.log` の 409 行目は `ZFILES ZFILES ACCENT index=0APPEARANCE appearance=0 accent=0`: desktop の Files の `ZFILES ACCENT index=0` と Files の窓の `ZFILES APPEARANCE appearance=0 accent=0` が混ざって 1 行になっている。`fm_log`（`userland/desktop/files/ui.c`）は unbuffered の stderr に prefix・本文・改行を 3 回に分けて書いていたので、同じ session の log を共有する 2 つの Files の行が途中で切れる。AAT の `ZFILES ACCENT index=0\b` は `index=0A` で一致しない。Purple の時は混ざらなかっただけ。Settings の書き方（既定でも `kl_settings_set` で "0"）と `kl_settings_watch`（compositor は chosen の値を送り、cache は値の違いで通知する）に問題は無かった。

## 直し

- `fm_log` は prefix・本文・改行を 1 つの buffer（1024 byte、長い本文は切り改行を残す）に作り、`write(2)` 1 回で書く。
- AAT `desktop.appearance.accent`（`plan/tools/aat/scenarios/helpers_desktop.py`・`tests/scenarios/desktop/appearance/accent.md`）は両方の step で `ZFILES ACCENT index=N` を必須にした。

| `make … build/p2-k/bin/files`（config/ci/config-amd64.mk） | 成功、warning 0 |
| `sh plan/tools/files/host-build.sh` → `strace -f -e trace=write build/ws071-host/files-model DIR` | files-model PASS、`ZFILES` の行は全部 1 回の write（改行込み、例 `write(2, "ZFILES THUMB …", 136)`）、`write(2, "ZFILES ", 7)` は 0 回 |
