# BUG-050: libc の `strerror` が多くの errno を "Unknown error" と返す

Bug ID: `BUG-050`
Reproduction: reproduced（QEMU、amd64 guest。`for i in 1..89: strerror(i)` の program で決定的）
Disposition: tracking
Date: 2026-09-25
Source: BUG-049 の調査で `route: Unknown error`（ENETUNREACH 33）、bind の EADDRINUSE（36）が名前で出なかったとき。
Owner: 未定。
Queue: なし。

## 期待と観測・影響

期待: `include/uapi/errno.h` の全ての値に `strerror` が文を返す。

観測: 29〜31、33〜40、43〜45、53〜66、82 以上が "Unknown error"。68〜81（2026-09-25 に追加）と 1〜28、32、41、42、46〜52、67 は文がある。`src/libc/string.c` の `strerror` の switch に case が無い。

影響: エラーの報告が読めない（route、networkd、configure の check の出力）。動作には影響しない。

## 再開の条件

`src/libc/string.c` に errno.h の全 case を足す（libc の変更は guest の LLVM package の再 build を伴う。F-012）。受け入れ: 上の program で 1〜`errno.h` の最大値の全てに文がある。
