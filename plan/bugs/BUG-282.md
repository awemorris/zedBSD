# BUG-282: bluetoothd の HID が page の途中に同じ機器の Connection Request を断ると、page の失敗と取り違える（潜在）

Reproduction: unknown（source の読み、2026-10-10 P1 の WS197 p003 の設計の review で見つけた）
Disposition: tracking（ベータ3。release の bluetoothd にある潜在の競合、起きる条件は狭い）
Discovery: 2026-10-10 P1（WS197 p003 の設計）
Handling: WS143（hid.c）、WS197 p003 の linkmgr の page と受けの交差の直しと同じ形で直す

## 内容

userland/base/bluetoothd/hid.c の hid_request（1259〜1266 行あたり）: PAGING の間に同じ機器から来た Connection Request を Reject すると、Core 7.1.9 によりローカルの Connection Complete（失敗 0x0D）が来て、router が linkmgr の page の token を外し、HID はそれを自分の page の失敗と見る。controller の Create Connection はまだ出ていて、後の成功は route が無く切られ得る。
