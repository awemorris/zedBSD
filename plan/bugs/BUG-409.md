# BUG-409: ld.so（src/rtld）が DF_1_NODELETE を守らず、dlclose で参照が 0 になると unload する

- 状態: open（2026-11-02 10:21 Q1 が起票、P3 q1930）
- 発見: 2026-11-02 10:21 WS335 p039 の Sonnet。libcrypto-compat.so は `-z nodelete` で link し FLAGS_1 に NODELETE を持つが、`src/rtld/rtld.c` の `__rtld_dlclose` は参照が 0 で object を unload し、`src/rtld/` に DT_FLAGS_1 を読む所が無い。dlopen・dlclose で使うと、thread の終わりの destroy の関数の code が unmap された後に呼ばれる恐れがある（DT_NEEDED で link する使い方では起きない）。
- 直す形: rtld が DT_FLAGS_1 を読み、DF_1_NODELETE の object（とそれが依存する object）は dlclose で unload しない。RTLD_NODELETE の dlopen の flag も同じ扱いにする（POSIX の範囲で）。
- 扱い: P3（q1930）。
