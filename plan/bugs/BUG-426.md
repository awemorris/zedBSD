- 状態: closed（2026-11-13 Q1。今の main の Pi 5 で再現せず。関係する直しは BUG-412 の Logitech の vendor の report を捨てる直し（82f7aba10a、報告の source にも入っていた）。再発したら受信機の型と log を報告者に頼む）
- 発見: 2026-11-13 外部の利用者の Raspberry Pi 500（BCM2712 D0、8 GB）での報告（source c4cede8、2026-11-03）。
- 起きた事: 初期設定のウィザードの後の最初の session で、カレンダー以外のアプリを click しても反応しない事があった。再起動の後は普通に起動する。Pi 5 の click の件（BUG-412・BUG-345）との関係を確かめる。

## 2026-11-13 P1 の確かめ（q2042-i01）: 再現せず

- 板と試験の build は BUG-425 の記録と同じ（Pi 5、10.0.30.5、main の userland と試験の kernel・compositor、試験の後に元へ戻した）。この板の user は初期設定がまだ済んでいない状態（起動のたびにウィザードが出る）で、初回の起動と同じ経路になる。

- 未実施: 実際の mouse の click（注入の pointer で確かめた）、Pi 500 の実機。
