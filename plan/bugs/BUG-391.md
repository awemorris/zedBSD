# BUG-391: compositor が落ちると login の画面から出直し、keyboard の無い tablet では login できない

- 状態: open（2026-11-02 01:27 Q1 が起票）
- 発見: 2026-11-02 ユーザーの Pi 5 の UAT。compositor が落ちた時に login の画面から再スタートする。tablet では keyboard の入力ができないので login できない。
- 期待（ユーザー）: いきなり desktop の表示から再開してほしい。
- Q1 の判断: 落ちた時に session の画面が lock されていなかったら、認証なしで同じ利用者の desktop から再開する。lock されていたら、lock の画面（BUG-392 の PIN の入力）から再開する（lock を飛ばさない）。sessiond が「同じ seat・同じ利用者の session の出直し」と「新しい login」を見分ける。
- 扱い: P8（q1890）。QEMU で compositor を落として確かめる。
