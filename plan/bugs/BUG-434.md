# BUG-434: clang の driver の -static（crt1.o + libc.a）で link できない（libc.a に system call の stub が無い）

- 状態: open（2026-11-14 Q1 が起票。BUG-432 の P2 の報告から）
- 観測（P2、未確かめ）: clang の driver に `-static` を付けて link すると、crt1.o と libc.a の組で `__syscall6` など 3 個が未定義になる。tree の static の program は `crt0.o` + `libc.a`（crt0 が system call の stub を持つ）で link しているので起きない。
- 扱い: libc.a に system call の stub を入れる（mk の libc.a の規則）か、driver の -static を crt0.o に向けるか。Makefile・mk の変更になるので、Q1 が差分の案を作ってユーザーに見せる。
