# BUG-257: Settings の Users の「New PIN」の欄に入力すると Settings が終了する

- 状態: reproduced（QEMU、T1-373、2026-10-08、2 回とも） / resolved（2026-10-08 T1-376 (b) PASS: PIN の 3 欄に数字・文字・7 桁目・Backspace・Left を打っても Settings は生き `KWL CLIENT gone` 0 件、6 桁が揃うと Set Up PIN が有効。PNG は T1 の worktree build/t1-376b-pin/）
- 発見: T1-373（WS090 p007 の Settings の欄の kl_field の手の確認、標準の AAT の image、1280x800 glass）
- 証拠: /home/awe/zedBSD-worktrees/t1/build/t1-373/session-run1.log の 2586 行 `KWL CLIENT gone client=7 reason=read`、2 回目は client=8 の同じ行。PNG 126・131・133（Settings が消え Files だけ）。

## 次

- WS090 p007（Settings の欄を kl_field へ）の PIN の 3 つの欄の経路を読み、落ちる所を直す。host で再現できれば host 試験に足す。

## 原因と修正（2026-10-08、P1）

- 原因（読んで決めた、host での再現は未）: `settings/page-users-pin.c` の `se_users_pin_key` は、key を `se_field_key`（libkeiland の `kl_field`）に渡した後で「欄の最後の文字が数字でないか 7 文字目なら `length--`」で取り消していた。`kl_field` の caret・anchor は動かないので caret が text の長さを越え、次の key（文字の挿入・Backspace）が欄の text の外を memmove して Settings が SIGSEGV（`KWL HOME ended … status=11`）。数字でない文字（PIN の欄は IME を受けないので直接の文字）か 7 桁目を打った後の次の key で落ちる。p007 で欄を `kl_field` に替えた時に、caret の無い古い欄の取り消しの書き方が残った。
- 修正: Ethernet の欄（`wired.c` の `se_wired_type`）と同じく、欄に渡す前に落とす: PIN の 2 つの欄で、Ctrl の無い文字の key が数字でなければ、または 6 桁で選択が無ければ、key を取って捨てる。後からの取り消しを除いた。
- 確認: zedBSD の settings の build（warning 0）、`make keiland-linux`（gcc）warning 0、style-check 0。Settings の PIN の頁の host 試験は無い。QEMU（T1）: Users の PIN の 3 つの欄に数字・文字・7 桁目・Backspace・Left を打って Settings が生きている、6 桁で 2 つが揃うと Set PIN が押せる。
