# BUG-035: `posix-r2-remaining.c` が compile できない（16 byte の atomic が `-Werror`）

Bug ID: `BUG-035`
Reproduction: reproduced（host の build）
Disposition: resolved（ws056-p001。`left`・`right` を `uint16_t` に。`POSIX-R2-REMAINING.ELF` が build でき 01-12 PASS）
Date: 2026-09-24
Source: ws046-p007（q411-i01）で `$(BUILD)/POSIX-R2-REMAINING.ELF` を作ろうとしたとき。
Owner: WS056 p001
Queue: q423-i01。

## 期待と観測・影響

期待: `make BUILD=... $(BUILD)/POSIX-R2-REMAINING.ELF`（amd64）が通る。

観測: `userland/base/tests/posix-r2-remaining.c:1566`・`1570`・`1594` で
`error: large atomic operation may incur significant performance penalty; the access size (16 bytes) exceeds the max lock-free size (8 bytes) [-Werror,-Watomic-alignment]`。
試験の code が 16 byte の object に atomic の操作をしている。この ELF はどの image にも入っておらず、既定の build では作られない。

影響: POSIX の残りの項目の試験が走らない。製品の code には影響しない。

## 再開の条件

POSIX の試験を回帰に戻す WS で。受け入れ案: 試験を 8 byte 以下の atomic か lock に直して compile でき、guest で status 0。
