# BUG-363: zedBSD の image に /etc/hosts が無く、名前の解決で localhost が引けない

- 状態: open（2026-10-30 Q1 が登録）
- 発見: 2026-10-30 P2（q1697-i02、WS327 p003 の guest の試験）。`kl_socket_resolve("localhost")` が ENOENT。image に /etc/hosts が無く、DNS も localhost を答えない（libkeiland の層は正しい）。
- 影響: localhost の名前を使う program（試験・app）が名前の解決で失敗する。
- 直す方針: base の image に /etc/hosts（`127.0.0.1 localhost`・`::1 localhost`）を入れる（userland の etc の雛形）。または libc の resolver が localhost を常に答える。どちらかは直す担当が POSIX・既存の etc の扱いを見て決める。
- 回避: WS327 の guest-layers.sh は捨てる guest に loopback の 2 行を足している。
