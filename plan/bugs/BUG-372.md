# BUG-372: VisionFive 2 の今の main の kernel で、serial の console が入力を受けない

- 状態: open（2026-10-30 登録、担当は未定）
- 発見: 2026-10-30 P2（WS291 p020、VF2 の serial /dev/ttyUSB0）。main の kernel で `login:` まで出力は出るが、CR や文字を送っても echo も応答も無い。
- 疑い（未確かめ）: WS331 p005 で VF2 の console を共通の boot-fb・fb-text に移し、ns16550 を「serial の送信」に渡す形にした時に、受信（入力の thread）を繋いでいない。Pi の rpi-console.c は UART の送受信と入力の thread を持つ。
- 影響: VF2 で network が上がらない時に、serial から操作できない。
- 直す方針（案）: VF2 の platform の glue（src/kern/platform/visionfive2.c）で、Pi と同じく UART の受信を tty の入力に繋ぐ。
