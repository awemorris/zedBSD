# BUG-043: `posix-r2-remaining.c` の scm-emfile が既定の descriptor の限界（1024）では EMFILE に届かない

Bug ID: `BUG-043`
Reproduction: reproduced（QEMU、amd64 guest）
Disposition: resolved（ws056-p001。試験が `RLIMIT_NOFILE` を 16 に下げる）
Date: 2026-09-25
Source: ws056-p001（q423-i01）で、BUG-035 を直して初めて走った `POSIX-R2-REMAINING.ELF` が `POSIX_R2R_FAIL: scm-emfile errno=40` で止まったとき。
Owner: WS056 p001
Queue: q423-i01。

## 期待と観測・影響

期待: `test_scm_rights()` は descriptor の表を一杯にしてから SCM_RIGHTS の受け取りが EMFILE になることを確かめる。

観測: 試験は `/tmp` を最大 32 回 open して EMFILE を待つが、kernel の限界は `KERN_OPEN_MAX` = 1024 で `RLIMIT_NOFILE` も既定で同じなので 32 回で埋まらず、errno は前の試験（unix-vfs の connect）の ECONNREFUSED（40）のまま。試験の前提の誤りで、製品の誤りではない。

影響: この ELF の 03 以降の試験が走らない。

## 修正

試験の中で `RLIMIT_NOFILE` の soft limit を 16 に下げてから埋め、受け取りの再試行の後に戻す。

## 再開の条件

ws056-p001 の結果で `POSIX-R2-REMAINING.ELF` が 03 を通れば resolved。
