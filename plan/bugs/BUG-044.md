# BUG-044: `posix-r2-remaining.c` の posix-close が `posix_close()` の返り値に errno の値を期待する

Bug ID: `BUG-044`
Reproduction: reproduced（QEMU、amd64 guest）
Disposition: resolved（ws056-p001。試験を -1 と errno=EINVAL の判定に）
Date: 2026-09-25
Source: ws056-p001（q423-i01）で、BUG-043 を直した `POSIX-R2-REMAINING.ELF` が 10 まで通った後 `POSIX_R2R_FAIL: posix-close errno=3` で止まったとき。
Owner: WS056 p001
Queue: q423-i01。

## 期待と観測・影響

期待: POSIX Issue 8 の `posix_close()` は成功で 0、失敗で -1 を返し errno を設定する（`close()` と同じ）。libc（`userland/base/libc/posix.c`）はそのとおりで、不正な flag では fd を閉じたうえで -1・`EINVAL`。

観測: 試験は `posix_close(fd, 1) != EINVAL` で失敗と判定し、返り値に errno の値（pthread 系の流儀）を期待していた。errno は 3 = zedBSD の `EINVAL` で、libc は正しい。試験の誤り。

影響: この ELF の 11 以降（12 の atomic、BUG-035 の目標）が走らない。

## 修正

試験を `posix_close(fd, 1) != -1 || errno != EINVAL` に直す。

## 再開の条件

ws056-p001 の結果で `POSIX-R2-REMAINING.ELF` が 11 を通れば resolved。
