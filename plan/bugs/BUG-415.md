# BUG-415: ブラウザ: back/forward の cache に保たない頁を離れる時に pagehide（persisted false）が出ない

- 状態: fixed（2026-11-02 P8 q1977-i01。host で確かめた、QEMU・実機は未実施）
- 発見: P8 q1941 で pagehide・pageshow を足した時の残り。cache に保つ頁は pagehide（persisted true）を出すが、保たない頁を離れる時は pagehide を出していない（HTML の unload の手順では persisted false で出す）。
- 扱い: P8（ブラウザ）。

## 修正（2026-11-02 P8 q1977-i01）

- `page_unload`（`page/script.c`）: HTML の「unload a document」（salvageable が false）の形で、window を unloading にし、頁が showing なら pagehide（persisted false）、次に window に unload（target は document、load と同じ）、その後に microtask。listener が頼んだ遷移は頁と一緒に捨てる。
- 頁の showing（HTML の page showing）: `struct page` の `showing`。pageshow で立ち、pagehide で落ちる。pagehide は showing の時だけ出す（cache に入れる時の persisted true も同じ）。
- 呼ぶ所（`view/view.c`）: cache に保てない頁（no-store、media を再生中）を離れる時と、同じ段の再読み込み・location.replace などで頁を置き換える時。cache に保つ頁は今までどおり pagehide（persisted true）だけで unload は出さない。cache から追い出す頁（数の上限）は HTML どおり event を出さずに消す。
- iframe（`page/frame-load.c`）: 離れる document の pagehide に persisted が無かった（`bind_fire_event` の普通の event）。`bind_fire_page_transition` で persisted false にし、その後に unload を出す。どちらの後も frame がまだこの読み込みの物かを確かめる。
- 試験: `plan/ws074/tests/host-back-forward.c` に足した。no-store の頁は離れる時に pagehide false の後に unload（target は document）を受ける。location.replace で置き換わる頁と、読み込み中の script の遷移で置き換わる頁も pagehide true が無く unload を受ける。cache に保つ頁は保たれている間 unload を受けない。
