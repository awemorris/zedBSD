# BUG-247: docked の窓の bar を touchpad で 2 回 tap しても docked が解けず、3 回要る（5320 実機）

- 状態: reproduced（実機 5320、ユーザーの UAT 2026-10-07） / resolved（2026-10-08 夜 ユーザーの実機の確認「Touchpadは動作確認できたので、下記をすべてclose します。BUG-156 (scrolling), 166 (title-bar drag), 167 (physical click), 178, 190 (touch-down as a press), 211 (inertial scroll), 215, 216 (Wiseview gestures), 228, 247, 254, and the touchpad part of 218」）
- 発見: 2026-10-07 ユーザーの UAT（5320、touchpad、ベアメタル）

## 観察（ユーザーの文）

「Dock barを2回タップして最大化モードを解除したいのですが、タッチパッドだと3回クリックしないとできないようです。最大化の時はフローティングのタイトルバーを2回タップすれば最大化できるので、解除も2回タップでできるとうれしいです。」

## 疑い（Q1、未確認）

- 最初の tap が bar の別の処理（focus・activate、BUG-245 の corner のような先の handler）に取られて double-click の 1 回目に数えられない。
- または 5320 の touchpad は sampling（6・25 ms）で読み、tap の押下・解放の時刻が double-click の間隔の判定とずれる（ws118-p007）。
- floating の titlebar の 2 回 tap（docked に）と bar の 2 回 tap（解除）を同じ判定にそろえる。

## 次

- P2: 5320 の session.log（`sshpass -p kei ssh kei@10.0.30.5`、読むだけ）で bar の press・double-click の行を見て直す。

## 原因と直し（2026-10-07 P2）

- 5320 の session.log: bar の title の tap のたびに `KWL GLASS pull back`（press で pull が始まり、指の揺れで pull_distance が 0 より大きいまま離れた）が出て、2 回目の press が double click にならず（`leave via=double-click` が出ない）、3 回目か、その後の drag（`leave via=pull`）で解けていた。
- 原因（推定、log と code から。press の時刻は log に無い）: touchpad の tap は press を指が離れた時に出し、release は次の tap が離れるまで（`TAP_DRAG_MS` の間）保つ（`touchpad.c`）。double click の判定（`double_click`・`title_clicks`、`DOUBLE_CLICK_MS` 400 ms）は前の press からの時間だけを見るので、2 回目の press は 1 回目の tap から丸ごと 1 tap 後（tap の間隔＋sampling の 25 ms の遅れ）になり、400 ms を越えやすい。bar の title では 1 回目の press が pull を始め、2 回目の指の揺れで窓が揺れて戻る（pull back の animation）ので、間隔がさらに延びやすい。
- 直し（`userland/desktop/wayland/shell.c`・`kwl.h`）: (1) double click の 2 回目は、前の press から **または前の release から** `DOUBLE_CLICK_MS` 以内なら数える（新しい `click_quick`、bar の `double_click` と floating の title の `title_clicks` の両方。release の時刻は `kwl_glass_button` が左の release ごとに `click_release_ms` に）。touchpad の double tap では 1 回目の release が 2 回目の press の直前に来るので必ず数えられる。(2) bar の title の pull は 8 px（`PULL_SLOP`）までの揺れでは窓が付いて来ない（揺れでの pull back の animation も出ない）。
- 確かめ: zedBSD の compositor と Linux の Keiland の build warning 0。実機（5320 の touchpad）で bar の 2 回 tap で解ける、floating の title の 2 回 tap で docked になる・3 回で後ろへ、mouse の double click も今どおり（ユーザーの UAT か T1）。

## 2026-10-08 P2 の確認（q869）

- 実装済み（b7a139874）: wayland/shell.c の release の時刻の記録、`click_quick`、`PULL_SLOP`（kwl.h の新しい field）。
- 証拠: build の warning 0 だけ。host の試験・QEMU（T1）は無い。
- 残り: 5320 の touchpad で、bar の 2 回 tap で解ける・title の 2 回 tap で docked・3 回で後ろへ・mouse の double click は今どおり（ユーザーの UAT）。
