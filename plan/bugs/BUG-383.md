# BUG-383: libbrowser が http の page からも file: の副資源（画像・script・style・font・media）を読む（local の file が web の page から読める）

- 状態: assigned（2026-11-01 05:06 P3 q1812、RTX の区切りの後）。元: open（2026-11-01 02:43 Q1 が起票、P7 の WS334 の設計のレビュー #2 で見つかった）
- 中身: `page/link.c` の `page_fetch` は、file: の URL の副資源を http・https の page からも読む。frame だけが止められている。web の page が利用者の local の
  file を読める（POSIX）。Windows では UNC の file: の URL（`file://host/share`）で利用者の NTLM の認証が漏れ得る（WS334 の契約では `wb_os_path_from_url` が
  host 付きを ENOENT にして閉じた）。
- 直す方針（案）: file: の副資源は file: の page からだけ許す（他のブラウザと同じ）。WS074 の領域。
- 影響: 安全（local の file の読み出し）。
