# BUG-396: Windows 版ブラウザ: Reload の button が文字で、icon でない

- 状態: fixed（2026-11-02 P8 q1914-i01、ad14a7ab44。Windows 版は icon。zedBSD・Linux・FreeBSD の compositor の題の帯は文字のまま（下の「残り」）。本物の Windows は未実施）← open（2026-11-02 06:16 Q1 が起票、P8 q1914）
- 発見: 2026-11-02 06:16 ユーザーの Windows での OmniGrammaton（WS334 の Windows 版ブラウザ）の UAT。
- 中身: Reload の button を文字でなく icon にしてほしい（他の button と揃える）。
- 扱い: P8（q1914）。このセッションで直す（ユーザーの指示）。描画と JavaScript の全般の改善はクラウドのセッションの libbrowser を待つが、この Bug はこのセッションで直す。

## 原因（2026-11-02 P8）

- browser の shell（`userland/desktop/browser/shell/titlebar.c`）が Reload を `KL_CONTROL_GENERIC`（label の pill）で宣言していた。
  Back・Forward は役割（`KL_CONTROL_BACK`・`_FORWARD`）から icon が決まるが、reload の役割が libkeiland に無かった。全ての platform で文字だった（zedBSD の compositor の `shell_icon` も GENERIC は label を描く）。

## 修正（ad14a7ab44）

- `<keiland/keiland_titlebar.h>` に `KL_CONTROL_RELOAD`（17）を足し、`KL_VERSION` を 106 にした。
- Windows（`userland/desktop/libkeiland/win32/titlebar.c`）: 既存の icon の組の `KL_ICON_REFRESH` を他の button と同じ 16 px の icon で描き、置き場所を左の Back・Forward の次にした（browser の普通の並び）。
- Wayland の libkeiland（`userland/desktop/libkeiland/titlebar.c`）: 題の帯の protocol に reload の役割が無いので、compositor へは `KL_CONTROL_GENERIC` として label 付きで送る（今までと同じ見た目、compositor は変えない）。
- shell は `KL_CONTROL_RELOAD` を使う。

## 確認

- Wine の screenshot で Reload が icon（↻）になり、Back・Forward の次に並んだ（`build/review/ws334-p033/titlebar-caption.png`、wine-run の caption の項目）。
  hit test で Reload の上は HTCLIENT（押せる）。wine-run の M4（Back の click と box の入力）も PASS。
- wine-run.sh の全体（2026-11-02、ad14a7ab44 の tree）: 21 PASS・0 FAIL・6 未実施（本物の Windows の項目）。144 dpi の帯も PASS（`build/review/ws334-p033/titlebar-144dpi.png`）。
- build: Windows warning 0、cross-build.sh PASS、host-build plain warning 0、`libkeiland/titlebar.c` を host の clang・gcc（-Wall -Wextra -Wconversion）で -fsyntax-only して警告 0。
- 未実施: 本物の Windows での見た目。zedBSD・Linux の compositor での確認（送る物は前と同じ）。

## 残り

- zedBSD・Linux・FreeBSD の compositor の題の帯は Reload を文字のまま描く。icon にするには、題の帯の protocol の版を 6 に上げて役割 17 を通し、compositor に reload の icon（`userland/desktop/wayland/icons.c` の GLASS_ICON）と `shell_icon` の対応を足し、
  libkeiland が版 6 の compositor にだけ 17 を送る形が要る。範囲（Windows の題の帯と icon）の外なので Q1 の判断に回す。
