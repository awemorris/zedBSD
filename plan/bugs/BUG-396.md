# BUG-396: Windows 版ブラウザ: Reload の button が文字で、icon でない

- 状態: fixed（2026-11-02 P8 q1920-i01、f48cf97e92 ほか。zedBSD・Linux・FreeBSD の compositor の題の帯も icon。QEMU の amd64 Venus で確認。本物の Windows・実機は未実施）← fixed（2026-11-02 P8 q1914-i01、ad14a7ab44。Windows 版だけ icon）← open（2026-11-02 06:16 Q1 が起票、P8 q1914）
- 発見: 2026-11-02 06:16 ユーザーの Windows での OmniGrammaton（WS334 の Windows 版ブラウザ）の UAT。
- 中身: Reload の button を文字でなく icon にしてほしい（他の button と揃える）。
- 扱い: P8（q1914）。このセッションで直す（ユーザーの指示）。描画と JavaScript の全般の改善はクラウドのセッションの libbrowser を待つが、この Bug はこのセッションで直す。

## 原因（2026-11-02 P8）

- browser の shell（`userland/desktop/browser/shell/titlebar.c`）が Reload を `KL_CONTROL_GENERIC`（label の pill）で宣言していた。
  Back・Forward は役割（`KL_CONTROL_BACK`・`_FORWARD`）から icon が決まるが、reload の役割が libkeiland に無かった。全ての platform で文字だった（zedBSD の compositor の `shell_icon` も GENERIC は label を描く）。

## 修正（ad14a7ab44）

- `<keiland/keiland_titlebar.h>` に `KL_CONTROL_RELOAD`（17）を足し、`KL_VERSION` を 106 にした。
- Windows（`userland/desktop/libkeiland/win32/titlebar.c`）: 既存の icon の組の `KL_ICON_REFRESH` を他の button と同じ 16 px の icon で描き、置き場所を左の Back・Forward の次にした（browser の普通の並び）。
- Wayland の libkeiland（`userland/desktop/libkeiland/titlebar.c`）: 題の帯の protocol に reload の役割が無いので、compositor へは `KL_CONTROL_GENERIC` として label 付きで送る（今までと同じ見た目、compositor は変えない）。
- shell は `KL_CONTROL_RELOAD` を使う。

## 残りの直し（2026-11-02 P8 q1920-i01）

- 元の「残り」: zedBSD・Linux・FreeBSD の compositor の題の帯が Reload を文字で描いていた（題の帯の protocol に reload の役割が無かった）。Q1 が q1920 で割り当てた。
- 題の帯の protocol（`kl_titlebar_manager_v1`・`kl_titlebar_v1`）を version 6 に上げた（compositor の `wayland/protocol.c`、libwayland の `titlebar-protocol.c`）。
  compositor（`wayland/titlebar.c`）は version 6 以上の client の `add_control` で role 17（`KWL_CONTROL_RELOAD`）を受ける。version 6 未満の client の 17 は今までどおり `invalid_value`。
- compositor の描画: `wayland/icons.c` に `GLASS_ICON_RELOAD`（大半の円と、左上の端の矢じり。libkeiland の refresh の icon と同じ形）、`titlebar-shell.c` の `shell_icon` で 17 → この icon、置き場所は Back・Forward と同じ左（`shell_side`）。
- libkeiland（`libkeiland/titlebar.c`）: bind を version 6 まで上げ、`KL_CONTROL_RELOAD` を version 6 の compositor には 17 で、古い compositor には `KL_CONTROL_GENERIC`（label 付き）で送る。KL_VERSION は 106 のまま（API は増えない）。
- 文書: `keiland_titlebar.h` の `KL_CONTROL_RELOAD` の注釈、protocol の設計（[WS070 の titlebar の設計](../ws070/titlebar-design.md) の §2.2、`add_control` の行と role の行）。
