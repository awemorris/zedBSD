## 観測

F9: IME を off にした入力は OK だが、key を押し続けた時のリピートが安定しない。表示の更新の揺れ（合成の間隔）の可能性もある。

2026-10-04 夜 UAT-3: [BUG-191](BUG-191.md)（Settings の repeat の設定が 5330 のキーボードに効かない）と同じ根の可能性。一緒に直す。

## 原因と直し（2026-10-05 q726、P2）

- 主な原因は [BUG-191](BUG-191.md) と同じ: PS/2 の typematic の make code が新しい press として client に届き、client の repeat の delay を毎回やり直していた（kernel の driver で直した）。
- もう 1 つ、client の repeat の拍: 次の repeat を「処理した時刻 + 間隔」で決めていたので、loop の起きるのが遅れる度に拍が伸び、描画の重い時に repeat の間隔が揺れた。次の repeat を「予定の時刻 + 間隔」にし（間隔より遅れた時は今から数え直し、まとめて打たない）、待ち時間も実際の残りを返す。`libkeiland/ui/window.c`（Terminal・TextEdit など）、`settings/window.c`、`files/window.c`、`browser/shell/window.c`、IME の `ime/method.c`。
- 確認: build（warning 0: zedBSD の terminal・textedit・settings・files・wayland、browser の shell の object、Linux の Keiland（IME を含む、-Werror））。拍の変更は小さく host の試験は足していない（読みで確認）。
- 未実施: QEMU（BUG-191 の `ps2-repeat-qemu.sh` は kernel の側だけを見る）、実機の 5330 の体感（UAT）。WS139 の P-02（合成の間隔）との関係は未調査。
