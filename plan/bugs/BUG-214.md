# BUG-214: Settings の窓の透明度の slider が初期値 100% なのに実際はもっと透けている（動かして 100% に戻すと不透明）

Reproduction: reproduced（ユーザー、実機 5330、2026-10-06 UAT）
Disposition: resolved（2026-10-08 夜 ユーザー「下記は実装の変更が多かったので、いったんすべてcloseします。」、Q1 の中継）
Discovery: 2026-10-06 ユーザーの UAT のコメント
Handling: WS089・BUG-171

## 観測（ユーザー）

「Settingsでウィンドウの透明度が初期値100%のスライダー値になっていますが、実際にはもっと低い透過表示の状態です。スライダーを動かして小さくしてから100%に戻すと、不透明の背景になりました。」

## 次（未確認の見込み）

既定値の不整合（設定の key の未設定時の既定と compositor の既定）。BUG-171 の決定 B（明示に 100 を選んだ時だけ不透明、既定は frosted）と slider の初期表示が食い違っている。slider の既定の表示を実際の既定に合わせるか、仕様をユーザーと確かめる。

## 2026-10-06 ユーザーの決定

クリックの回答「slider を磨りガラスの値に（推奨）」: 既定の見た目（frosted）は変えず、slider の初期の位置を実際の透明度に合わせる。

## 2026-10-06 ユーザーの決定（実際の値の出し方）

P1 の案 (1)〜(3) へのクリックの回答「slider と switch に分ける」: slider は窓の中身の不透明度（85〜100、既定 100）だけにし、「Frosted glass」の switch（既定 on）を別に置く。off で不透明の地（BUG-171 の solid）。

## q800-i01（P1、2026-10-06）: 直し

Status: test-wait（T1 依頼中）

ユーザーの決定（Q1 経由）「slider と switch に分ける」に従った（commit 6fd5968f）:
- 新しい key `window.frosted`（bool、既定 1、`userland/desktop/settings-keys/settings-keys.c`）。
- compositor（`userland/desktop/wayland/settings.c` の `settings_apply_opacity`）: `window.opacity` は窓の中身の不透明度だけ。glass の panel は
  `window.frosted` が 0 に選ばれた時だけ solid（BUG-171 の決定 B「100 を選ぶと solid」を置き換えた）。log の形
  `ZWL PREFERENCES key=window.opacity applied value=N panels=glass|opaque` は同じ（`window.frosted` の変化でも出る）。
- Settings の Appearance の「Windows」の card: slider は 85〜100% の中身の不透明度（100 でも「Opaque」でなく「100%」と表示）、その下に
  「Frosted glass」の switch（既定 on、off で panel が solid、log `LOOK set key=window.frosted value=0|1`）。既定の見た目（frosted）は変わらず、slider は
  既定で 100% の正しい位置になる。
- 試験: `plan/ws089/tests/settings-p007.sh` の 3b を `set window.frosted 0` → `value=85 panels=opaque` に、reset に `window.frosted` を足した。

確認: host の描画で Appearance の頁（switch の on・off、click で `LOOK set key=window.frosted value=0`）。`plan/tools/settings/host-store.sh` 43 passed、
`host-settings.sh` 38 passed。build（settings・wayland）warning 0、keiland-linux.mk exit 0。QEMU は T1（settings-p007.sh）。

注: 以前に `window.opacity=100` を選んで panel を solid にしていた利用者は、この版から frosted に戻る（solid にするには switch を off に）。
