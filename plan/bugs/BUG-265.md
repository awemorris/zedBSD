# BUG-265: 浮いた titlebar でダブルタップからドラッグすると、ダブルクリックとして窓が最大化（dock）される

- 状態: reproduced（実機 5330、2026-10-08 午後 ユーザーの UAT） / scheduled
- 由来: ユーザー「ウィンドウのフローティングタイトルバーで、ダブルタップからドラッグする標準的なモーションを行おうとすると、ダブルクリックとして認識されて、ウィンドウが最大化＝ドックされます。ダブルタップの2回目の指のタッチが離れた瞬間にダブルクリック判定すれば、回避できると思います。」

## 期待

- ダブルタップ（2 回目も離す）→ 最大化（dock）。
- ダブルタップの 2 回目で押したまま動かす（tap-and-drag）→ 窓の移動。最大化しない。
- 判定は 2 回目の指が離れた時（動きが閾値を超えていればドラッグ、超えていなければダブルクリック）。

## 担当

- 2026-10-08 午後 Q1: P1 に割当（ws189-p004 の前）。titlebar の press の扱い（compositor の titlebar か libkeiland の kl_titlebar）、touchpad の tap（WS183・native の touchpad）と touchscreen の両方で。
