# BUG-432: 静的に link した program の stdout が、file への出力の時に exit で flush されない

- 状態: open（2026-11-14 Q1 が起票）
- 発見: 2026-11-13 P1（WS353 p002 の QEMU の試験の program、手で static に link）。WS299（5330 の NVMe）でも「return の時の stdout の flush」が見つかっていた（master の「Q1 が決める事」の Bug 化の候補）。
- 観測（P1、未調査）: stdout を file に向けた時、`exit`（か main の return）で中身が書かれない。
- 扱い: libc の exit の流れ（atexit・stdio の flush）を調べて直す。動的に link した program で起きるかも確かめる。
