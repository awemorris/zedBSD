# BUG-278: 状態の島のパネルの Mute の button の文字が右にずれる

Reproduction: reproduced（ユーザー、実機 5330、2026-10-10 UAT）
Disposition: tracking
Discovery: 2026-10-10 ユーザーの 5330 の UAT のコメント（image はユーザーの 5330 に入っていた物、版は未確認）
Handling: WS192

## 観測（ユーザー）

「通知アイコンのタップでポップアップを出せた。でもMuteボタンのテキストが右にずれている。」（T1-496 の PNG でも左に空きがあった、Q1）

## 原因と直し（2026-10-10、P1）

`glass_draw_text_middle`（`userland/desktop/wayland/glass.c`）の「middle」は「長い時に真ん中を省く」の意味で、x は行の**左端**。状態の島のパネルの Mute の button（`status-panel.c`）は button の**中央**を x に渡していたので、文字が中央から右へ描かれた（文字幅の半分だけ右にずれ、左が空く）。
同じ誤用が通知の履歴（`notify-log.c` の「No notifications」と「Clear all notifications」の button）と通知の popup の頭文字の tile（`notify-popup.c`）にもあった。

直し: `glass_draw_text_centred`（中央の x、文字幅を測り左端を出して `glass_draw_text_middle` を呼ぶ）を `glass.c`・`glass.h` に足し、4 か所をそれに替えた。greeter・keyboard・titlebar は左端を渡しており正しい。
確かめ: `make BUILD=build/amd64 build/amd64/bin/wayland` warning 0、style-check の変更箇所 0。
未実施（T1）: 状態の島のパネルの PNG（T1-496 と同じ手順）で Mute の文字が button の中央、通知の履歴の空の板の文字が中央。実機は次の UAT。
