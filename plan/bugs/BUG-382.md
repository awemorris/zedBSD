# BUG-382: 5330 の NVMe の p7 を discard して起動した直後に、mkfs が "no registration" で失敗する（約 2 分後なら通る）

- 状態: in-progress（2026-11-01 05:06 P2 q1811）。元: open（2026-11-01 02:19 Q1 が起票）
- 発見: 2026-11-01 P1（WS299 の 5330 の計測、q1788、main 82c6ef325 の image）。`plan/ws299/tests` の p7fswrite の段で、p7 の discard と起動の直後に
  2 回 `mkfs failed: no registration`。起動の約 2 分後に手で流すと通り、script の 3 回目（q1788-Z4）も通った。
- 疑い（未確かめ）: discard の後、NVMe の名前空間・区画の登録（partition の probe か device の登録）が起動の後しばらく終わっていない、または discard の完了を待たずに次へ進む。
- 影響: 5330 で起動の直後に新しい区画に file system を作れない事がある（間欠）。
