# BUG-284: Settings の Ethernet の頁に wlan0（Wi-Fi）の card が出て「No cable」と表示される

Reproduction: reproduced（実機 5330、2026-10-10）
Disposition: scheduled（ベータ2、P1）
Discovery: 2026-10-10 BUG-277 の確かめ（ユーザー「wlan0でした。ue0はConnectedです。」）
Handling: WS089（Settings の Network）・libkeiland-backend-zedbsd の interface の種類の判定

## 観測

Settings → Network の Ethernet の頁に「wlan0」の card があり No cable。5330 の wlan0 は `flags=UP,BROADCAST,MULTICAST`（RUNNING 無し）`media: unknown`。Wi-Fi の interface が wired の card に入っている見込み（種類の判定）。
