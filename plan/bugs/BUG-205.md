# BUG-205: app 全般で太字の font が美しくない（anti-alias が regular と違って見える）

Reproduction: reproduced（ユーザー、Windows の QEMU（Venus）で uat-0505g、2026-10-05 夜 UAT）
Disposition: tracking
Discovery: 2026-10-05 夜 ユーザーの UAT のコメント
Handling: WS090（widget の library）・libtruetype

## 観測

ユーザー「アプリ全般、フォントの太字が美しくない。アンチエイリアスがレギュラーと違う感じがする。太字フォントを採用するか、グリフを太くするアルゴリズムをベクターで実装するか、どちらか。」

## 原因（2026-10-06 P1）

libkeiland の `kl_text`（`userland/desktop/libkeiland/ui/text.c`）と、その写しの Files・Text Editor の `text.c` は、太字を **coverage の bitmap の上の
擬似の太字**で作っていた: 普通の glyph を描いてから、各画素を左隣との大きい方に置き換えて 1 画素右に塗り広げ、advance を 1 足す。
anti-alias の端が片側だけ濃く伸び、stem ごとに太さが揃わない（regular と違う anti-alias に見える）。

## 選んだ方式と理由（2026-10-06 P1）

- ユーザーが認めた 2 案: (a) 本物の太字の font、(b) libtruetype で outline を vector で太らせる。
- 調べた事実: 収録の `Inter.ttf` は variable font（fvar: wght 100〜900、opsz 14〜32、gvar・HVAR・avar あり）。libtruetype は fvar/gvar を読まず、
  instance を作れない。gvar の対応（共有 tuple・IUP の補間・avar・HVAR の advance）は大きく、CJK の fallback（DroidSansFallbackFull、1 weight）は
  どちらにしても太字が無い。
- **(b) を採用**: 正しく作れて、Inter と CJK の両方に効くため。FreeType の `FT_Outline_EmboldenXY` と同じ考え方（各 vertex を 2 辺の法線の二等分線の
  方向に、両辺が強さの半分だけ離れる距離（miter）動かす。内側の角は短い方の辺の長さまでに抑える。ほぼ折り返す vertex は動かさない。outline の回る向き
  （面積の符号）で ink の側を決める）。outline は既に線分にしてあるので、描く形に対して正確。
- 強さ: 横 1/22 em、縦 1/36 em（太字の font は縦の stem を横の bar より太くするので）。全体を半分だけ右上へ寄せ、左の端と baseline を保つ。
  advance は横の強さを四捨五入した画素だけ増やす。host で Inter の本物の wght 700（PIL）と並べて見て決めた（`build/bug205/compare.png` は worktree の中、
  各 size で上から regular・新しい太字・旧の擬似太字・本物の 700）。
- 後の改善の候補（未実施）: libtruetype に gvar を足し、Inter の本物の weight を使う（Latin だけ。CJK は (b) のまま）。

## 修正（2026-10-06 P1、agent/p1）

- libtruetype: `truetype_set_bold(face, bold)`（公開、`keiland/truetype.h`・`libtruetype/exports.map`）、`truetype_outline_embolden()`（`outline.c`）、
  `glyph.c` の measure が bold の face で outline を太らせ advance を足す。`face.c`・`internal.h`。
- `libkeiland/ui/text.c`・`files/text.c`・`textedit/text.c`: 擬似の太字（画素の塗り広げと advance の +1）をやめ、`truetype_set_bold` で描く。
- 対象外: libbrowser の自前の太字（`libbrowser/text/font.c`、ブラウザのレンダリングの作業は止めている）、zdesktop の bar・titlebar（P2 の担当の file）。
- 確認: zedBSD の build（libtruetype・libkeiland・phone・mailer・calendar・files・textedit・settings）warning 0。host: `plan/ws035/tests/truetype-test.c` を
  DejaVu Sans で PASS（Inter では変更の前から「I is nearly as tall as the ascent」が FAIL、この試験は DejaVu 向け）。ASan・UBSan の下で Inter・DejaVu Sans/Serif・
  DroidSansFallback を 9〜50 px で太字に描いて誤り無し。`run-host-phone.sh` 15/15、`host-widgets.sh` 94/94。
