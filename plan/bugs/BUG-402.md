# BUG-402: ブラウザ: Google の app の一覧の popup の中の app の icon（画像か SVG）が出ない

- 状態: fixed（2026-11-02 P8 q1924-i01、agent/p8-uat2。GPU の描画で atlas より大きい画像が描かれなかった。host の GPU（lavapipe）と Wine の OmniGrammaton で確かめた、本物の Windows は未実施）。前: open（2026-11-02 08:19 Q1 が起票、P8 の待ち行列）
- 発見: 2026-11-02 08:19 ユーザーの Windows での OmniGrammaton の UAT（BUG-397〜399 の直しの後）。
- 中身: BUG-398 の直しで popup は出るようになったが、中の app の icon が表示されない（Wine の画面では出ていたので、本物の Windows との違いか、取得の経路の違いも疑う）。
- 扱い: P8（ブラウザの担当、ユーザーの決定）。BUG-401 の後に順に。

## 原因（2026-11-02 P8）

Windows に固有ではなく、libbrowser の GPU の renderer（`paint/vulkan.c`）の制限。app の一覧の icon は 1 枚の sprite（`p_2x_….png`、106×6138 px）を `background-image` にし、`background-position` で 1 つずつ見せている。GPU の renderer は画像を 2048×2048 の atlas に写して描くが、atlas より大きい画像は「後で」として描かずに捨てていた（`gpu_place_image`）。CPU の描画（`browser_view_draw_pixels`）は描くので、CPU で描く道具（BUG-398 の P7 の clickprobe、Wine の画面もそれ）では出ていた。Vulkan で描く OmniGrammaton（本物の Windows も Wine も）と zedBSD の browser では出なかった。

確かめ: 自分で作った 40×3000 の縦の sprite（`plan/ws074/tests/pages/tall-sprite.png`）の頁を `browser --render` と `--render-gpu` で描くと、直す前は CPU だけが描き、GPU は白。直す前の OmniGrammaton.exe（Wine、lavapipe）も白だった。

## 直し（2026-11-02 P8、`userland/desktop/libbrowser/paint/vulkan.c`）

atlas より大きい画像は、その描画の切り取った矩形が見せる部分（texel の範囲）だけを atlas に写す（`gpu_stage_part`・`gpu_place_part`）。その部分がまだ atlas より大きければ k texel おきに写す。instance の原点・倍率・texel の数をその部分に合わせて動かすので、shader は同じ texel を見つける。写した部分は画像の serial・範囲・間引きで覚え、同じ frame の中で使い回す。atlas の画像の記録（`struct paint_gpu_image`）に部分の範囲を足した（画像全体は step 0）。

## 確かめ（2026-11-02 P8）

- 新しい host の試験 `plan/ws074/tests/host-tall-image.c`（引数なし、`tall-sprite.html`、icon 5 つ: 上の帯、終わり近くの帯、background-size で縮めた画像の帯）。CPU の色が帯の色で、GPU（lavapipe）が CPU と同じ色かを見る。後は 15 checks PASS。直す前の object では GPU の 3 つ（atlas を越える位置と縮めた物）が白で 5 FAIL。
- Wine（x86_64、lavapipe、cross-build の OmniGrammaton.exe）: `tall-sprite.html` は直す前の .exe で 4 つとも白、後は帯の色。live の google.com で右上の app の一覧の button を押すと、後は icon が出た（PNG は worktree の `build/review/bug402/` の `wine-apps-after.png`・`wine-sprite-before.png`・`wine-sprite-after.png`）。
- host build（`host-build.sh plain`）warning 0。host-* の exit は前と同じで、新しい試験 1 本が増えた。`cross-build.sh` PASS。zedBSD amd64 の `libbrowser.so` warning 0。
- 未実施: 本物の Windows の GPU。zedBSD の画面（QEMU・実機）。
