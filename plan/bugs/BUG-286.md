# BUG-286: NFC の YubiKey で Settings の鍵の登録と、NFC のタッチでのログインが失敗する（USB では動く）

Reproduction: reproduced（ユーザー、実機 5330、2026-10-10）
Disposition: scheduled（ベータ2、WS199 の中で P1、ユーザーの「全部ベータ2」）
Discovery: 2026-10-10 ユーザーの UAT
Handling: WS199・WS161（NFC、p005 の transport-nfc）・passkey-fido2

## 観測（ユーザー）

「NFCのYubiKeyは、認識はされてるけど、鍵の登録はSettingsからは失敗。USB接続で設定した鍵で、NFCタッチでログインしようとしたが、失敗。USB接続では問題なく使えた。」

## 原因（Q1 の source の読み、2026-10-10）

/usr/libexec/passkey-fido2 の `fido2_devices_open`（userland/base/passkey-fido2/device.c）は `pk_os_list` の USB の HID（hidraw）の鍵だけを開く。NFC の reader（/dev/smartcard*、libpasskey の transport-nfc、ws161-p005）は fidoctl では使えるが、登録と login の経路には無い。docs/architecture/security.md の「Keys plugged in or tapped during the attempt are asked too」とずれている。P1 の WS199 の review の M4 と同じ。

## 直し

passkey-fido2 の鍵の一覧に NFC の card を足す（root で /dev/smartcardN を開き、card がある slot を鍵として扱う。silent の問い合わせ・PIN・assertion・registration を同じ libpasskey の CTAP2 で）。
