# BUG-429: TCO の watchdog が sleep の suspend の途中の停止を捕まえない（PCI の順の早い所で counter を halt する）

- 状態: open（2026-11-13 Q1 が起票、BUG-424 の P2 の案から）
- 発見: 2026-11-13 P2（BUG-424 の試験、5330）: TCO は SMBus（00:1f.4）の PCI の suspend で counter を halt するので、その後の device の suspend・resume で止まっても reset しない。watchdog の thread は CPU の停止しか見ない。案: 全 device の suspend の後・CPU が idle に入る直前に halt し、起きた直後に re-arm。sleep の suspend・resume が N 秒を超えたら叩くのをやめる期限。
- 関係: [BUG-424](BUG-424.md)（VMD の S0 idle）。S0 idle の試験を 5330 で安全に流すには両方が要る。
