# BUG-366: device の mmap で MAP_FIXED が hint として扱われる（POSIX は指定の address か失敗）

- 状態: open（2026-10-30 Q1 が登録） → closed（2026-10-31 Q1 の判定、main f81fef099。2026-10-31 P2、q1750-i01、QEMU で確かめた。実機は未実施。Q1 の判定待ち）
- 発見: 2026-10-30 WS009 p024（DOC-54 の正確さの review、source の読み）。
- 場所: `src/kern/syscall.c` の mmap の device の枝と `src/kern/vm/device.c` の `vmspace_map_device`。GPU の node の mmap で MAP_FIXED の address が守られない。
- 影響: MAP_FIXED を使う program が別の address を受け取る（POSIX.1-2024 の mmap は MAP_FIXED で指定の address に map するか失敗する）。未確かめ（実行で再現していない）。
- 直す方針: device の枝でも MAP_FIXED の address に map し、出来なければ失敗を返す。docs/reference/gpu-memory.md は今の動き（hint）を書いているので、直したら合わせる。

## 修正（2026-10-31 P2、q1750-i01）

- 変更（e722b9556）: `vmspace_map_device` の `int exact` を placement（`include/kern/vmspace.h` の VM_DEVICE_PLACE_HINT・NOREPLACE・FIXED、kernel の内の API で HAL ではない）にした。MAP_FIXED は `vmspace_map_device_replace`（`src/kern/vm/vmspace-map.c`、prepare_region で region を先に作り device の参照と max_prot を付けてから vmspace_replace_prepared で置き換える。anon・file の MAP_FIXED と同じ道）で、指定の address に、範囲にあった物を置き換えて map するか失敗する。`src/kern/syscall.c` は MAP_FIXED を FIXED、MAP_FIXED_NOREPLACE を NOREPLACE で渡す。`docs/reference/gpu-memory.md` を合わせた。
- build: amd64 の vmunix は warning 0。QEMU（amd64、intel-hda + hda-duplex の /dev/dsp0、audiod を止めて、SSH）で、anonymous の 4 page の 2 page 目に `mmap(…, MAP_SHARED | MAP_FIXED, dsp, 0)` が指定の address を返し、書けて、隣の anonymous の page も使え、同じ所への MAP_FIXED_NOREPLACE が EEXIST、空いた page への MAP_FIXED も指定の address を返した。修正の前の kernel での再現は未実施（source の読みの通り hint だった）。GPU の node での確かめは未実施。
