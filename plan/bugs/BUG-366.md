# BUG-366: device の mmap で MAP_FIXED が hint として扱われる（POSIX は指定の address か失敗）

- 状態: open（2026-10-30 Q1 が登録）
- 発見: 2026-10-30 WS009 p024（DOC-54 の正確さの review、source の読み）。
- 場所: `src/kern/syscall.c` の mmap の device の枝と `src/kern/vm/device.c` の `vmspace_map_device`。GPU の node の mmap で MAP_FIXED の address が守られない。
- 影響: MAP_FIXED を使う program が別の address を受け取る（POSIX.1-2024 の mmap は MAP_FIXED で指定の address に map するか失敗する）。未確かめ（実行で再現していない）。
- 直す方針: device の枝でも MAP_FIXED の address に map し、出来なければ失敗を返す。docs/reference/gpu-memory.md は今の動き（hint）を書いているので、直したら合わせる。
