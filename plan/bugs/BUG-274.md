# BUG-274: `ps -o args` が argv[0] だけを出す（引数が出ない）

- 状態: reproduced（QEMU、2026-10-09 P1 の調べ） / scheduled
- 観察: src/kern/exec.c が process の command に argv[0] だけを写すので、`ps -A -o pid,args` の args に引数が出ない。POSIX の ps の args は「command と引数」。
- 影響: 試験が引数で process を探す所が一致しない。2026-10-09 に 2 つの試験の不具合の根になった（T1-475 の u-guest の `wltest --app-id=u.a`、aatlib の stop_programs の `files --desktop`）。
- Q1 の判断（2026-10-09）: kernel の process の command に引数まで（上限つき）持たせ、ps の args に出す。試験は今の直し（pid で除く）のままでよい。
- 担当: P1（ベータ2 の合間、小さい）。
