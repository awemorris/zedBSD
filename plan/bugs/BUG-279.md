# BUG-279: Settings で「No security key registered」と出て YubiKey を操作できない

Reproduction: reproduced（ユーザー、実機 5330、2026-10-10 UAT）
Disposition: resolved（2026-10-10 ユーザーの UAT「FIDO2のキー登録とログインができました。」、fidoctl set-pin の後に Settings で登録）
Discovery: 2026-10-10 ユーザーの 5330 の UAT のコメント（image はユーザーの 5330 に入っていた物、版は未確認）
Handling: WS161・WS172（Settings の security key の頁、鍵の登録の経路）

## 観測（ユーザー）

「SettingsでNo security key registeredでYubikeyを操作できなかった」

## 解析と直し（2026-10-10、P1、source）

Settings の Users の頁の Security keys の card（`userland/desktop/settings/page-users-keys.c`）は、鍵を足すのに「今の password」「鍵の名前」「鍵の PIN（4 字以上）」の 3 つを要し、揃うまで「Add Security Key」の button を押せない。
買ったままの YubiKey には FIDO2 の PIN が無く（PIN は `fidoctl set-pin` で付ける、UAT の手順の 14）、PIN を打てないので button は押せないまま、card は「No security key is registered.」としか言わなかった。ユーザーの「操作できなかった」はこの見込み（鍵に PIN があったか、3 つを打ったかは未確認）。

直し: 答えの文が無く Add が押せない間、card の下の行に何が要るかを出す（PIN が 4 字未満: 「Type the key's PIN. A new key needs one first: run fidoctl set-pin in Terminal.」、他: 「Type your password and a name for the key, then its PIN.」）。登録の経路そのものは変えない。
確かめ: `make BUILD=build/amd64 build/amd64/bin/settings` warning 0、style-check 0。
残り（判断）: Settings の中で鍵の PIN を付ける（fidoctl set-pin の代わり）はベータ3 の候補（Q1 へ）。
未実施: 実機 5330 の UAT（YubiKey 5 で PIN を付けて登録、ロック画面で使う）。QEMU に FIDO の鍵は無い。
