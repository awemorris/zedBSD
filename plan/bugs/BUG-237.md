## 観測（ユーザー）

「アプリアイコンはよいです！ただ、白抜きの部分が透過になっていない気がします。透過にするように指示したと思います。」

## 解析と修正（2026-10-06 P2、ws128-p012）

- 合成そのものは正しかった: 記号の所は alpha 0（premultiplied の over、B8G8R8A8_UNORM、identity swizzle、opaque 0）。白の hover の重ねも tile の alpha を coverage にするので記号の所は変えない。
- 原因: light の外観で tile の下の地がどこも白に近い glass（App Home は白 0.48 を shader が luma 0.85 以上に持ち上げ淡い青を重ねた地、bar 0.55、Alt+Tab 0.66、title bar）。抜いた記号にはその白い地が見え、白い記号に見えた。
- 修正: `glass_draw_app_tile` に `enum glass_hole`。`GLASS_HOLE_SCENE` は tile の内側（辺の 0.08 内）に glass が曇らせている blur の景色をそのまま描いてから tile を重ねる。App Home は常に SCENE、bar・title bar・Wiseview・Alt+Tab は light の外観で SCENE、dark で GROUND（暗い地が見える）。
- 証拠（host）: `plan/ws128/tests/hole-host.sh`、[bug237-hole.png](../ws128/phase012/images/bug237-hole.png)。記号の中の全画素が blur の景色と差 0/255（前は地と差 0）、tile の縁は前後で同じ。build warning 0（zedBSD・Linux）、style-check 0。
- 未実施: 実機・QEMU の画面。Disposition は Q1 が UAT の確認で決める。
