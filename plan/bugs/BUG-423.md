# BUG-423: QEMU amd64 で USB の keyboard が enumerate されない（`usb0: port 6 enumeration failed (42)`）

- 状態: open（2026-11-13 Q1 が起票）
- 発見: 2026-11-13 P2（BUG-422 の確かめ）。QEMU amd64 `-smp 4`（KVM、`plan/bugs/BUG-422/qemu-boot.sh`）で、guest の USB の keyboard が `usb0: port 6 enumeration failed (42)` で使えず、login の key が届かない。42 は `ETIMEDOUT`（`include/uapi/errno.h:83`）。画面の login prompt までは出る（boot-test PASS）。
- 回帰の見込み: 2026-10-17（BUG-333 の T1-707）には qemu-xhci の usb-kbd が enumerate していた。BUG-422 の前の kernel（sha256 716c57ba9d6c5091、WS333 p025 の c6）でも同じに失敗するので、BUG-422 の直しとは関係しない。build system の作り直し（2026-11-06）か、その後の xHCI・USB の変更の見込み（未確かめ）。
- 影響: QEMU の amd64 で key の入力を使う試験（login・guest の操作）が全部できない。実機は未確かめ。
- 確かめ: `plan/bugs/BUG-422/qemu-boot.sh` の `LOGIN=1`。QEMU の command line（`-device qemu-xhci`・`usb-kbd`、`-smp`）の違いで変わるかも見る。
