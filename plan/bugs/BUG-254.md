# BUG-254: touchpad の右端からの 2 本指 swipe が、片方の指だけ端だと認められない（左端は認められる）

- 状態: reproduced（実機、ユーザーの UAT 2026-10-07） / scheduled（P2、q856-i01 で修正を実装、host 試験 PASS、実機の UAT 待ち）
- 発見: 2026-10-07 ユーザー「トラックパッドの左端からの2本指スワイプは、片方の指がエッジにあれば認識されました。しかし、同じことが右端では認識されないようです。2本の指がエッジにないとだめみたいです。もしくは、私の指の付き方にクセがあるのかも。2本同時にタッチしないといけないように感じます。ちょっとでも時間差があると認識されないかもしれない。」

## 疑い（Q1、未確認）

- ws181-p008（930fc5dbc）の `edges_of_fingers` の「どれか 1 本」の判定が、2 本目の指が遅れて着いた時に、1 本目の着いた時の位置だけで（または 2 本が揃った時の位置で）決まり、右端の帯の幅・座標の向き（右端は max 側）で外れる。左右で判定の式か帯が非対称の可能性。
- 指の着く時間差の扱い（2 本目が着くまでに 1 本目が動いて帯を出る、gesture の開始の判定の時刻）。

## 次

- touchpad.c の端の判定を左右・上下で対称にし、指の着く時間差（例 150 ms まで）を許す。host 試験（host-gesture.c）に時間差と右端の case を足す。5330・5320 で UAT。

## 解析（P2、q856-i01、host 試験で確認）

- 同時に着いた 2 本の指で片方だけ右端の帯の中（新しい case 27）は、修正の前の code でも RIGHT2 になった。判定の式（`x >= x_max - band`）そのものは左右で同じ。
- 外れるのは指の着く時間差: 2 本目の指が着いた時（`fingers_changed`）、端は「今の位置」で、しかも touch の travel が 3 mm（TAP_TRAVEL_UM）未満の時だけ判定していた。1 本目が着いてすぐ内へ動き始めると、2 本目が着く時には帯の外・travel 3 mm 超で、端が無い → scroll になる。修正の前の code で、4 つの端の全てで「端の指が先に着き、0.5 mm/8 ms で動き、もう 1 本が約 130 ms 後」（case 28）と「内の指が先に着いて動き、右端の指が約 100 ms 後」（case 29）が FAIL（9 of 79 checks）。左右の差は指の着き方の癖による（式の非対称ではない）と見る。
- もう 1 つの非対称: 左端・上端を 0 から測り、右端・下端を axis の最大から測っていた。axis の最小が 0 でない pad では左・上の帯が狭くなる（または消える）。

## 修正（P2、q856-i01）

- `userland/desktop/wayland/touchpad.c`・`touchpad.h`: 指ごとに着いた位置と時刻（`start_x`・`start_y`・`start_ms`、report の始めに fresh の指から取る）を持ち、端は**着いた位置**で判定する。2 本の指の着いた時刻の差が `STAGGER_MS`（150 ms）以内なら、1 本目がその間にどれだけ動いても端を保つ（`fingers_landed_together`）。それより離れた時は従来どおり travel 3 mm 未満の時だけ。
- 帯は各端の axis の端から内へ測る（左・上は最小 + 帯、右・下は最大 − 帯）。`kwl_touchpad_set_range`（最小と最大）を足し、`kwl_touchpad_set_size` は最小 0 の wrapper として残す。`input.c` の attach_touchpad は evdev の absinfo の minimum を渡す（1 行）。
- 時間差の間、1 本目の動きは pointer を動かす（gesture の travel には入らない）。これは残る挙動。
- 試験: `plan/ws142/tests/host-gesture.c` に case 27〜31（右端の片方の指、4 端の時間差、内の指が先、400 ms 後の 2 本目は scroll、最小が 0 でない axis の左・上と帯の外）。`plan/ws142/tests/run-host-gesture.sh` ok（82 checks）、`plan/ws159/tests/run-host-touchpad.sh` ok（25 checks）、input.c・touchpad.c は keiland-linux の flag（gcc -Werror）で warning 0。
- 未実施: 5330・5320 の実機の UAT（ユーザー）。zedBSD の target の build（compositor 全体）は未実施（host の compile だけ）。
