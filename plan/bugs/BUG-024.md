## 静的な調査（2026-09-27、WS073）

- 現在の main: `config/drivers/pci.drivers`・`usb.drivers` の全ての行の platform は `i386,amd64`（または `amd64`）で、pc98 を含まない。
  `tools/menuconfig.py` の `applies()` はこれに従って PC-98 では PCI・USB の選択肢を出さない（報告どおり）。
- 原因は menu ではなく kernel の側: PC-98 の kernel（`platform/pc98/vmunix.mk`、`HAL_BOARD_PC98`）は PCI の bus の backend も USB の host
  controller も build しない。PC/AT は `drivers/pci/pci.o`・`pci-pcat.o`（config mechanism #1）と `pci-uhci`・`pci-ehci`・`pci-xhci` を
  `platform/pcat/vmunix.mk` で link するが、PC-98 には相当の配線・PCI の割り込みの経路（PC-98 の PIC の IRQ の割り当て）が無い。
  menu に選択肢を出すだけでは、選んでも何も build されない（誤解を招く）。
- 試験: PC-98 の build・QEMU・実機の試験は、試験を amd64 だけにする方針（2026-09-27）のため未実施。
