# BUG-380: Pi 4（V3D 4.2）で mview の vkCreateGraphicsPipelines が -8（FEATURE_NOT_PRESENT）を返し、3D の model が動かない

- 状態: closed（2026-10-31 22:19 Q1 の判定。P4 の 1f3eb15b3（discard）・f6e9074a9（blend）で Pi 4 の mview が動く。main に merge）
- 発見: 2026-10-31 P2（WS309 p015 の Pi 4 の試験）。`--shading=pixel`・`--shading=vertex` のどちらでも同じ。
- 原因の記録: [ws291-p021](../ws291/phase021/phase.md)（55 行あたり）に、Pi 4 と Pi 5 が共有する V3D の Vulkan の executor（`src/drivers/gpu/bcm2711/vk/`）が compositor の
  四角の形だけを受け、mview に要る物（mip level など）を受けない、とある。BUG-320（browser の -8）と同じ種類。
- 影響: Pi 4 で 3D の game・model の viewer が動かない。game mode の zero copy の 3D の確かめもできない（動画では確かめた）。Pi 5（V3D 7.1）も同じ見込み（未確かめ）。
- Q1 が確かめた事（同日）: mview に足りない機能（index の draw、instance の数と instance rate、mip の image、頂点の attribute の GPU の address の直の指定）は、
  WS291 p021 で P4 が host で実装済み（branch agent/p4-ws291pi の 6 commit、6334ae147〜f2f87ac1b、bcm2711 の 32 file +1064 行）だが、Pi 5 の実機で
  確かめるまで main に入れていない。Pi 4 の image は main から作ったので、この機能が入っていない。

## 原因と直し（2026-10-31 P4 q1784-i01、branch agent/p4-ws291pi）

- 6334ae147〜f2f87ac1b（p021）の index の draw・instance・mip・直の fetch に加え、Pi 4 の実機で一時の log の kernel で ENOTSUP の場所を特定し、残る 2 つを直した。
  1. V3D の compiler（4.2・7.1）に discard（IR の KILL）が無く、mview の cutout の fragment が拒否された → 1f3eb15b3（条件の flag の push と真の lane の SETMSF 0）。
  2. pipeline の blend が premultiplied の source-over だけで、mview の SRC_ALPHA・ONE_MINUS_SRC_ALPHA を拒否 → f6e9074a9（Blend Cfg の factor・mode を pipeline から）。
- 確かめ（Pi 4、10.0.30.6、1920x1080、kernel build/p025-4/vmunix）: mview qs40 の窓 59.1 fps、game mode の c1 86.3 fps・c21 33.65 fps、`lent=1 copies=0`、kernel の fault の行 0。
  正面の静止の画は目視で正しい（他の GPU の参照の画との pixel の比べは未実施）。host 試験 shader-host-test・bin-draw-host-test PASS。Pi 5（V3D 7.1）は build と host 試験まで（実機は p021）。
- 状態: Pi 4 では直った（main への merge は Q1）。Pi 5 の実機の確かめは p021。
