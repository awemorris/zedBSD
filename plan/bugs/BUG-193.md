# BUG-193: 起動の logo の画面の animation が、最初は速く、その後に通常の速さに戻る

Reproduction: reproduced（実機 5330、UAT 2026-10-05 午後）
Disposition: resolved（2026-10-08 夜 ユーザー「下記は実装の変更が多かったので、いったんすべてcloseします。」、Q1 の中継）
Discovery: 2026-10-05 午後 UAT（実機 Latitude 5330、image は 12 時の uat-0505c の見込み、sha256 018fa0bd…）
Handling: 起動の logo の描画（boot の splash）。担当は Q1 が割り当てる

## 観測（ユーザー）

「起動ロゴ画面、最初の方はアニメーションのペースが速く、そのあと通常に戻る。kernel tickの設定が影響している？実時間でアニメする必要があると感じました。」

## 期待

animation は実時間（monotonic の時刻）で進み、起動の途中の tick・timer の較正の変化や CPU の負荷に関係なく一定の速さで見える。

## 調べる点

- splash の描画が frame の数か tick（`kernel_ticks`・HAL_TIMER_FREQUENCY）で進んでいるか。起動の初めに timer の較正の前後で tick の周期が変わる（TSC の較正、LAPIC の timer の較正）なら、最初の速さが違う。
- 実時間に替えるには、`hal_rtc_read_counter()` の差か monotonic の clock で経過時間を測り、位相を時間から計算する。
- QEMU で再現するか（較正の前後の差が出るか）。

## 場所の確認（2026-10-05、P2 g15、q759。修正はしていない）

- 起動の logo の spinner は kernel の側: `src/drivers/platform/pcat/graphics/splash.c`（描画）と、それを進める `drv_pcat_splash_step()` の呼び手 `src/hal/amd64/bsp-pcat/cons.c:1070`（HAL の console、quiet boot で改行ごと）と `src/drivers/platform/pcat/graphics/text.c:411・869・1030`（kernel の text console、改行・行送りごと）。
- 原因: spinner は**時間でなく console の 1 行ごとに 1 コマ**進む（`splash.frame++`）。起動の初めは log の行が速く続くので速く回り、行が減ると遅くなる（tick の設定ではない）。行の出ない間は止まる。
- 直し方の案（P1 へ）: `drv_pcat_splash_step()` で monotonic の時刻（HAL の counter）から `frame = elapsed / 周期` を計算して、前のコマと違う時だけ描く（行が速く来ても速くならない）。行の出ない間も回すには、timer の callback（kernel の timer が使えるようになってから）で同じ step を呼ぶ。HAL の API は変えずに済む見込み（`src/hal/` の実装の中の呼び手と driver の中で閉じる）。
- 担当: kernel・driver なので P1（Q1 の指示どおり P2 は場所の確認まで）。
## 直し（2026-10-05、P1 generation18）

原因: spinner は `drv_pcat_splash_step()` の呼び出しごとに 1 段進んだ。呼び出しは log の各行（`cons.c`・`text.c`）と、`text.c` の
`text_splash_ticker` の 125 ms ごと。起動の初めは行が多く、段が行の数だけ足されて速く、行が減ると ticker の 125 ms だけになる。

直し（`src/drivers/platform/pcat/graphics/splash.c`・`text.c`、hal.h は変えない）: 段は HAL の monotonic counter
（`hal_rtc_read_counter()`）の経過時間 ÷ 125 ms（`SPLASH_STEP_MS`、1 秒で 1 周）で決め、段が変わった時だけ描く。最初に counter を読めた時の
段から時刻で続ける。counter が読めない間（HAL の初め、counter の無い HAL: i386 の pcat・pc98）は前のとおり 1 行 1 段。ticker は 25 ms ごとに
見る（描くのは段の変わり目だけ、4800 回で 2 分）ので、行の来ない間も一定の速さで回る。

確認: kernel の build（amd64、warning 0）。QEMU・実機は未実施（T1・UAT で起動の logo の速さを目で見る）。
