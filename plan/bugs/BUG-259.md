# BUG-259: PDF viewer の窓のリサイズのドラッグの応答が悪い

- 状態: reproduced（5330 bare metal、2026-10-08 ユーザーの UAT） / tracking（未割当）
- 発見: 2026-10-08 ユーザーの UAT（原文）:「PDFビューアでウィンドウをリサイズでドラッグするとき、リサイズイベントごとになんらかの重い処理をしているように見えて、レスポンスが悪い。毎イベントに完全な再描画や内部リサイズ処理をしないで、200msごとに内部リサイズをするとかはどうだろう。あとは、重い処理が不要な処理であればそもそも省くとか。たぶん画面描画の矩形が変わるだけの実装で十分なのに、内部バッファを作り直してソフトウェアレンダリングをやり直している気がする。」
- 疑い（未確認）: configure ごとに内部の buffer を作り直し、PDF の page を software で描き直している。

## 次

- PDF viewer の configure・resize の経路を読み、event ごとの処理を測る。
- 直しの方向（ユーザーの案）:
  - drag の間は描画の矩形・位置だけ変える。
  - 内部の resize と描き直しは 200 ms ごと、または drag の終わりにする。
  - 要らない重い処理は省く。
