## 2026-10-05 夜 ユーザーの追加

「QEMUのvirglrendererがフリーズするのはウィンドウを閉じるバツボタンを押したタイミングです。QEMUごと落ちます。でもこれは深追いしなくていいです。記録だけでいいです。」→ 窓の閉じる（×）の時に host の QEMU（virglrenderer）ごと落ちる。guest の窓の破棄（Vulkan の resource・blob の解放の順）が host の virglrenderer の不具合に当たる見込み。調査はしない（ユーザーの指示）。

## 2026-10-08 P2 の確認（q869）

- 修正は無い（2026-10-05 夜のユーザーの指示で、記録だけ）。Windows の QEMU（WHPX・Venus）で、窓の × の時に host の QEMU ごと落ちた（1 回）。host 側（virglrenderer）の挙動の見込み。
- QEMU・host の証拠: 無し。
