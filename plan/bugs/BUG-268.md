# BUG-268: eDP を off にして USB-C の DP だけで出している時、DP を抜くと eDP が戻るまで約 10 秒かかる

- 状態: reproduced（実機 5330、2026-10-08 夕 ユーザーの UAT） / scheduled
- 由来: ユーザー「eDPオフが機能しました。USB-C DPだけの出力ができました。ただ、USB-C DPを切断したあと、eDPが回復するのに10秒ほどかかりました。」（BUG-266 の直しの確認と同じ回）
- 証拠: [BUG-267/kernel.log](BUG-267/kernel.log) の 6066 行の前後（`resident display: ended FAIL (… first anomaly: the sink lost the link while the picture was up)` → `the moved output failed; the firmware's output (eDP panel) is the output again` → `lease 7 claimed` → `picture up` → `first frame 1920x1080 … shown on the 1920x1080 panel`）と [BUG-267/session.log](BUG-267/session.log)。
- 疑い（未確認）: 抜いた時に link の失敗の検出（HPD の後の 2 秒の再確認、presentation の timeout など）を待ってから eDP に戻している。抜いた（HPD の disconnect）時点で直ちに eDP へ戻すべき。
- 担当: 2026-10-08 夕 Q1: P2（BUG-266 の担当）に割り込みで。
