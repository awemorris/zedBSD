# BUG-437: idle の時に xHCI の port の worker の thread が 1 秒に 90〜100 回起きる（5330 の PC2 が下がる）

- 状態: open（2026-11-15 Q1 が起票。WS353 p016 の 5330 の thread ごとの起床の数で P1 が観測）
- 観測: 5330（Latitude 5330）の idle（既定の program の一式、kernel 6286bbd6 に WS352 の poll の診断の patch を一時に当てた run）で、`xhci_port_worker` の 2 本の thread が、それぞれ 1 秒に約 90〜100 回眠り直している。compositor の timeout は 0。CPU 0・1 の timer の割り込みは 1 秒に 700〜870 回。idle の package の電力は 4.54 W・PC2 66〜74 % で、WS333 p029（4.37 W・PC2 87 %）に届かない。
- 疑い（未確定）: xHCI の port の状態を周期で見に行く待ち（port の変化の割り込みで起こす形になっていない）。PC2 の差の主な原因の候補。
- 扱い: xHCI の driver（`src/drivers/usb/` の xhci）の port の worker の待ち方を、WS353 と同じ考え（事象で起こす、周期で見ない）で直す。確かめは QEMU の xHCI で起床の数、5330 で idle の電力と PC2。
- 関係: [WS353](../ws353/ws.md)（待ち方の作り直し）、[WS352](../ws352/ws.md)、[WS333](../ws333/ws.md)、[BUG-428](BUG-428.md)（xHCI の port 3 の resume）。
