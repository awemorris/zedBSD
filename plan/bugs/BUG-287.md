# BUG-287: スマホ（Pixel 10a）を pairing・Connect できても、Phone の app から送信すると Connect が切れて失敗する

Reproduction: reproduced（ユーザー、実機 5330、2026-10-10 深夜 UAT、image 19cef18）
Disposition: scheduled（ベータ2、WS197、P1）
Discovery: 2026-10-10 ユーザーの UAT
Handling: WS197（p004c の Use as phone・pairing の phone=1、Settings の Connect）

## 観測（ユーザー）

「スマホとBluetoothでペアリングできました。Connectもできました。」「Phoneアプリから送信しようとすると、Connectが解除され、通信に失敗しました。」

## Q1 の SSH（/var/log/messages の bluetoothd、session の log）

- 00:34:14 普通の pairing（`pairing 04:C8:B0:BC:8F:A5 bredr`）→ `PAIRED … authenticated=1 secure=1 … stored=0`。その前の 2 回は `pairing: ERROR rejected`。
- 00:34:28・00:35:52・00:37:14 `connecting 04:C8:B0:BC:8F:A5 bredr asked by uid 1000` → `hid: ERROR timeout`（Settings の Connect が **HID の接続**を試み、スマホは HID でないので 12 秒で timeout。Settings は `result kind=connect errno=33`）。
- 00:35:10 **`pairing 04:C8:B0:BC:8F:A5 bredr phone=1` → `pairing: ERROR rejected`**（「Use as phone」の pairing が 3 秒で断られた。その時は普通の bond が既にあった）。00:35:27 forget、00:35:36 普通の pairing で PAIRED（phone=1 ではない）。
- `bt bonds`: `BOND address=04:C8:B0:BC:8F:A5 type=bredr … name="Pixel 10a"`。
- session: `KWL PHONE state … linked=0 … why=no-record`、`PHONE LINK backend=0 … why=no-record`、`ZSETTINGS BLUETOOTH phone enabled=0 … why=no-record` → **phone の記録が無い**（phone=1 の pairing が成功していない）ので phone.backend=0、Phone の app の送信は backend 無しで失敗。

## 見込み（未確認）

1. 既に普通の bond がある機器に「Use as phone」（phone=1 の pairing、保存の鍵を使わない）をすると、スマホの側が断る（`rejected`）。既に bond がある時は鍵を作り直さずに phone の記録だけを作る道か、pairing の前に bond を消す道が要る。
2. Settings の Connect は HID でない機器にも HID の接続を試み、timeout で「切れた」に見える。スマホには Connect を出さない（Use as phone を出す）か、phone の link の接続にする。
3. Phone の app は backend 無しの時に「Settings で Use as phone を入れて」と案内すべき。
