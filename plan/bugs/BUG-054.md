# BUG-054: `/dev/fd/N` が開いた file ではなく文字 device として見え、`ls /dev/fd` で inode の pool が尽きる

Bug ID: `BUG-054`
Reproduction: reproduced（QEMU、amd64 guest、2026-09-26、決定的）
Disposition: scheduled（[WS067](../ws067/ws.md)、2026-09-26 ユーザー「BUG-054の修正を最優先」）
Date: 2026-09-26
Source: ws065-p001（q451-i01）。sh の process substitution の試験 `diff <(echo 1) <(echo 1)` が guest でだけ失敗した。
Owner: 未定
Queue: q454（ws067-p001）

## 期待と観測

期待: `/dev/fd/N` を `stat` すると、その descriptor が開いている file の情報になる（Linux の `/dev/fd` は開いた file への link、FreeBSD の fdescfs も同様）。`ls /dev/fd` は開いている descriptor だけを並べる。`diff` は FIFO・pipe の中身を読んで比べる。

観測（guest）:

| 操作 | 結果 |
| --- | --- |
| `ls -lL /dev/fd/0 </etc/passwd`、`echo x \| ls -lL /dev/fd/0` | どちらも `crw-rw-rw- ... /dev/fd/0`（regular file でも pipe でも文字 device） |
| `diff <(echo 1) <(echo 1)`（sh の process substitution。読むのは正しく動く） | `/dev/fd/3 and /dev/fd/4 differ: device identity`（`userland/base/diff/tree.c` は文字 device を `st_rdev` で比べる。FIFO は読まずに同じとする） |
| `ls /dev/fd/` | 1000 番台以降の名前が並び、各々 `Unknown error`。その後 SSH の接続が切れ、sshd が消えている（devfs の node ごとに inode を共通の pool（512、BUG-052）から取り、尽きたとみられる） |

## 直し方の候補

- devfs の `/dev/fd/N` の `stat` を、呼んだ process の descriptor N の `fstat` にする。readdir は開いている descriptor だけを返し、node を pool から取らない（または使い終わりで返す）。
- `diff` は FIFO と文字 device（と `/dev/fd`）を中身で比べる（GNU diff と同じ）。

## 再開の条件

devfs か base の utility を扱う WS で。sh（WS065）の範囲外。
