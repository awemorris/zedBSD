# BUG-395: Windows 版ブラウザ: 題の帯の address の欄の部分を drag して窓を動かせず、double click で最大化もできない

- 状態: open（2026-11-02 06:16 Q1 が起票、P8 q1914）
- 発見: 2026-11-02 06:16 ユーザーの Windows での OmniGrammaton（WS334 の Windows 版ブラウザ）の UAT。
- 中身: 題の帯に address の欄が組み込まれていて小さくてよい（ユーザーの評価）。一方、address の欄の周りの帯の部分を drag しても窓が動かず、double click でも最大化しない。欄の外の帯の余白は Windows の caption（HTCAPTION）として振る舞うべき。
- 扱い: P8（q1914）。このセッションで直す（ユーザーの指示）。描画と JavaScript の全般の改善はクラウドのセッションの libbrowser を待つが、この Bug はこのセッションで直す。
