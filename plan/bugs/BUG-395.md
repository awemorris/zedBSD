# BUG-395: Windows 版ブラウザ: 題の帯の address の欄の部分を drag して窓を動かせず、double click で最大化もできない

- 状態: fixed（2026-11-02 P8 q1914-i01、ad14a7ab44。Wine で hit test・drag・double click を確かめた。本物の Windows は未実施）← open（2026-11-02 06:16 Q1 が起票、P8 q1914）
- 発見: 2026-11-02 06:16 ユーザーの Windows での OmniGrammaton（WS334 の Windows 版ブラウザ）の UAT。
- 中身: 題の帯に address の欄が組み込まれていて小さくてよい（ユーザーの評価）。一方、address の欄の周りの帯の部分を drag しても窓が動かず、double click でも最大化しない。欄の外の帯の余白は Windows の caption（HTCAPTION）として振る舞うべき。
- 扱い: P8（q1914）。このセッションで直す（ユーザーの指示）。描画と JavaScript の全般の改善はクラウドのセッションの libbrowser を待つが、この Bug はこのセッションで直す。

## 原因（2026-11-02 P8）

- hit test（`userland/desktop/libkeiland/win32/frame.c`）は正しく、題の帯の control の外の pixel には HTCAPTION を返していた。
  直す前の build でも Wine で、address の欄と最小化の button の間の 10 px には HTCAPTION が返り、そこからの drag で窓が動き、double click で最大化した。
- 問題は配置（`userland/desktop/libkeiland/win32/titlebar.c` の `keiui_win32_titlebar_layout`）: address の欄（breadcrumb の box）が左の button と右の Reload・caption の button の間の幅を全部取り、
  高さも帯の 32 px のうち 30 px を取っていた。control の外に残るのは幅 10 px の隙間と 1 px の行だけで、事実上 drag・double click・右 click の場所が無かった。

## 修正（ad14a7ab44）

- `win32/titlebar.c` の配置: box の高さを 24 px（96 dpi、dpi に合わせて拡大）にして帯の中央に置き、下の帯（最大化の間は上も）を caption にした。
  box の幅は最大 800 px で、右の control の前に少なくとも 96 px の何も無い帯を残す（box の最小 120 px を守る時だけ譲る）。
  hit test は変えていない（control の外の帯は元から HTCAPTION）。drag での移動・Aero Snap、double click の最大化と復元、右 click の system menu は DefWindowProc がする。
- 1024 px の窓では box が x 118〜780、何も無い帯が 780〜886（その右が最小化の button）。

## 確認

- Wine（`plan/ws334/tests/wine-run.sh` に caption の項目を足した。`plan/ws334/tests/hit-test-main.c` が別の process から WM_NCHITTEST を送る）:
  - caption-hit: 何も無い帯（右端から 180 px）と box の下で 2（HTCAPTION）、box・Back・Reload で 1（HTCLIENT）、最小化の button で 8。PASS。
  - caption-drag: 何も無い帯からの xdotool の drag で窓が 0,0 → -100,50 に動いた。PASS。
  - caption-double: xdotool の double click で最大化（client 1280 幅）。復元は、Wine が window manager 無しでは最大化した窓の X の窓を動かさず xdotool で押せないため、
    frame に WM_NCLBUTTONDBLCLK（その点の hit test の答え）を送って確かめた（1280 → 1024）。
- wine-run.sh の全体（2026-11-02、ad14a7ab44 の tree）: 21 PASS・0 FAIL・6 未実施（本物の Windows の項目）。144 dpi の帯も PASS（`build/review/ws334-p033/titlebar-144dpi.png`）。
- 直す前の build での同じ点の hit test: box の右の 834・874 が 1（box の中）、新しい build では 2。
- build: `make -f apps/browser-win32/Makefile` warning 0、`plan/ws334/tests/cross-build.sh` PASS、`plan/ws074/tests/host-build.sh plain` warning 0、storage-test PASS（222）、scheme-test PASS（83）。
- 未実施（本物の Windows）: 実際の drag・Aero Snap、double click の最大化と復元、右 click の system menu、Windows 11 の snap layouts。
