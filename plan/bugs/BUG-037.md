# BUG-037: pax が pax 形式の拡張 header（typeflag `x`）を読めない

Bug ID: `BUG-037`
Reproduction: reproduced（QEMU、amd64 guest）
Disposition: resolved（ws056-p001。`x`・`g`・`L`・`K` を読む。GNU tar の pax・gnu の archive を guest で展開して host と一致）
Date: 2026-09-24
Source: ws046-p008（q412-i01）で、GNU tar の `--format=pax` で作った coreutils の source の archive を guest の `pax -r` で展開したとき。
Owner: WS056 p001
Queue: q423-i01。

## 期待と観測・影響

期待: POSIX の pax は pax interchange format（ustar に拡張 header の typeflag `x`・`g` を足したもの）を読める（XCU pax、"pax Interchange Format"）。

観測: `pax: unsupported archive member type x: coreutils-9.12/tests/wc/PaxHeaders/wc.pl` などを全ての member で出し、status 1。
（ustar の形式で作り直した archive は読めた。）

影響: 今の GNU tar の既定の形式や、長い名前・大きい file・細かい時刻を持つ archive を guest で展開できない。

## 再開の条件

pax（WS043 の utility）を扱う WS で。受け入れ案: `x`（path・size・mtime など）と `g` の header を読み、GNU tar の `--format=pax` の archive を展開して中身が一致する。
