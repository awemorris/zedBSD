# BUG-410: libc の atexit が登録した object を覚えず、dlclose した library の関数を exit で呼ぶ

- 状態: open（2026-11-02 10:41 Q1 が起票、P3 q1931）
- 発見: 2026-11-02 10:41 P3（BUG-409 の残り）。src/libc/stdlib-extra.c の atexit は、どの object が登録したかを覚えない。NODELETE でない library が atexit を呼んで dlclose されると、exit の時に unmap された code を呼ぶ。C++ の静的な object の後始末（__cxa_atexit と DSO の handle）も同じ。
- 直す形: __cxa_atexit（fn、arg、dso の handle）を持ち、atexit は呼んだ object の handle で登録する。dlclose で object を unload する前に、その object の登録を逆順に走らせて外す（__cxa_finalize(dso)）。
- 扱い: P3（q1931）。
