# BUG-428: S0 idle の devices の往復で xHCI の port 3 が resume で戻らず、USB の NIC（ue0）の受信が止まる（5330）

- 状態: open（2026-11-13 Q1 が起票、BUG-424 の P2 の案から）
- 発見: 2026-11-13 P2（BUG-424 の試験 b424d、5330、`sleepctl devices`）: 往復は `result 0 resume 0`、VMD・NVMe は戻ったが `xhci: port 3 did not resume (42)` → `usb-rtl815x: ue0 receive stopped (5)`。SSH の路が切れ、S0 の試験の結果を戻った後に読めない。
- 関係: [BUG-424](BUG-424.md)（VMD の S0 idle）。S0 idle の試験を 5330 で安全に流すには両方が要る。
