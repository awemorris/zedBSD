# BUG-203: Phone の app で日本語を入力できない（IME に対応していない見込み）

Reproduction: reproduced（ユーザー、Windows の QEMU（Venus）で uat-0505g、2026-10-05 夜 UAT）
Disposition: tracking
Discovery: 2026-10-05 夜 ユーザーの UAT のコメント
Handling: WS170（Phone）・WS095（IME）

## 観測

ユーザー「Phoneアプリで日本語が入力できない。IMEに対応していないっぽい。」

## 原因（2026-10-06 P1、source の読みで確認）

Phone・Mailer・Calendar の入力欄は libkeiland の widget の `kl_field` で、`kl_field` は US 配列の key（`kl_key_character`）しか受けず、
IME・画面 keyboard の text-input（`KL_WINDOW_TEXT_COMMIT`・`PREEDIT`・`DELETE`）の口が無かった。3 つの app は `kl_window_text_input` も
呼ばず（text-input が enable されない）、window の text の event は `default:` で捨てていた。Text Editor・Terminal は自前の入力で対応済み。

## 修正（2026-10-06 P1、agent/p1）

- libkeiland（KL_VERSION 38）: `kl_ui_text(ui, event)` が commit・delete を key と同じ queue に（来た順に）入れて focus の widget に渡し、
  preedit は focus の widget の caret に出す。`kl_ui_text_wanted(ui, &caret)` が「focus の widget が text を受けるか」と caret の矩形を返す。
  `kl_field`（secret でない物）が commit を選択の位置に入れ、delete で caret の前後を消し、preedit を caret に下線付きで描く。
  file: `userland/desktop/libkeiland/ui/ui.c`・`field.c`・`internal.h`、`keiland/keiland-ui.h`・`keiland.h`・`keiui.h`、`libkeiland/exports.map`。
- Phone・Mailer・Calendar の `main.c`: window の text の event を `kl_ui_text` に渡し、frame ごとに `kl_window_text_input(window, kl_ui_text_wanted(...))` と
  `kl_window_text_cursor` を呼ぶ。
- host 試験: `sh plan/ws170/tests/run-host-phone.sh build/bug203/host-phone` 15/15 PASS（追加 ime-wanted・ime-preedit・ime-commit・flick-voiced・ime-unwanted）。
  `sh plan/ws090/tests/host-widgets.sh build/bug203/host-widgets` 94/94 PASS。両方の試験は `kl_appearance_get` の未定義で link できなくなっていたので stub を足した（古い試験の直し）。
- zedBSD の build: `make ZEDBSD_CONFIG=plan/ws170/tests/config-amd64-phone.mk BUILD=build/p1-zed build/p1-zed/bin/phone build/p1-zed/bin/mailer build/p1-zed/bin/calendar` warning 0。
- 未実施: QEMU（T1 へ依頼）。Settings・Files の自前の入力欄、kuidemo は対象外（`kl_field` を使う app は main loop で同じ 2 行を足せば対応する）。
