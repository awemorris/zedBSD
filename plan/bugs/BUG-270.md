# BUG-270: touchscreen で画面の上端から下へ swipe しても窓の一覧（Wiseview）が出ない（未実装）

- 状態: reproduced（実機 5330、2026-10-08 夜 ユーザーの UAT、USB の外付け touchscreen） / scheduled
- 由来: ユーザー「画面上端からのスワイプダウンでウィンドウ一覧（Wiseview）が表示される機能が未実装でした。」（BUG-267 の確認と同じ回）
- 今: touchscreen の端の gesture は左右（desktop の切り替え）と下（Home）だけ（userland/desktop/wayland/touch.c・edge.c、BUG-267 の 1 本・複数本の group）。上端は system bar がある。
- 期待: 上端（bar の上か、bar の帯の中から）から下へ swipe → Wiseview を開く。1 本指も、一番外側の指が上端にある複数本の指も（BUG-267 のユーザーの規則と同じ）。bar の tap・bar の menu を壊さない。
- 担当: 2026-10-08 夜 Q1: P1（BUG-267 の edge の続き、WS143 i02b の区切りの後）。

## 原因と直し（2026-10-08 夜、P1）

- 原因: 上端から下への swipe（Wiseview）は WS181 で touch の上端の帯（`KWL_EDGE_BAND` 10 px、launcher と右上の角を除く）として作ってあった。BUG-267 の uat2/session.log の上端の試しは y=13〜31 に落ちていて（`KWL TOUCH shell contact=0 x=906 y=31`・`x=938 y=17`・`x=1033 y=18`・`x=899 y=17`・`x=934 y=13` など、`KWL EDGE band press` は 0 行）、帯に一度も入っていない。外付けの panel では指が上の縁から 13〜31 px に落ちるので、事実上使えなかった。複数本の指の上端は group に無かった。
- 直し:
  1. 1 本指: touch の帯の深さを、bar が指で引く物を持たない所では bar の高さ全体（`KWL_EDGE_BAND_DEEP` 44 = `KWL_GLASS_BAR`）に（`shell.c` の `band_depth`、`edge.c` の `kwl_edge_classify_band`）。docked の窓の menu・title・button の所（`menu_line` から close の button の先まで）は今までどおり 10 px（指で窓を引き下ろす・menu を開くのと取り合わないため）。帯の press は今までどおり、下へ 12 px で Wiseview、tap は離した時に bar に渡し直し（replay）、横・上へ 8 px で bar に渡し直す。launcher（x<40）と右上の角（28）は帯の外のまま。
  2. 複数本の指: BUG-267 の group に上端（`KWL_EDGE_SIDE_TOP`）を足した。一番外側の指が上の縁から 64 px 以内（bar の中なら shell が帯で取り、150 ms 以内の他の指は場所を問わずどこにも行かない。bar の下なら client の指として集め、全部が下へ動いたら上端の (x, 0) で shell に press を渡す）→ 帯の press → Wiseview。
- 制限: docked の窓がある時、その窓の bar の部分では 1 本指の帯は 10 px のまま（status・時計・desktops の pill の所は 44 px）。複数本の指ならどこでも上端の (x, 0) に寄せるので通る（launcher と右上の角を除く）。
- 確認: `sh plan/bugs/BUG-267/tests/run-host-touch-group.sh` → ok (70 checks)（足した case: 外側 900,50 と 950,400 が下へ → `edge group side=top … x=900 y=0`、bar の 1000,20 の後の 1100,300 → `edge joined`）、`plan/ws181/tests/run-host-edge.sh` → 69 checks failures=0（`kwl_edge_classify` は変えていない）。amd64 wayland（cksum 4169115077）・Linux wayland の build warning 0、style-check の新しい指摘 0（shell.c の 5 件は前から）。

### 5330 で見る物

1. 窓の無い desktop で、上の縁から 1 本指で下へ swipe（縁から 1 cm 以内、時計・status の所でもよい）→ Wiseview が開く。log `KWL EDGE band press x=… y=…`（y が 10〜43 でも）、`KWL WISEVIEW gesture via=top-edge`。
2. 2 本指（外側の指を上の縁の近くに）で下へ → `KWL TOUCH edge joined` か `KWL TOUCH edge group side=top`、続いて `KWL WISEVIEW gesture via=top-edge`。
3. bar の tap（時計 → Calendar、volume・network の icon、desktops の pill）が今までどおり動く（`KWL EDGE band replay release=1` の後に各 icon の行）。
4. 窓を最大化（docked）して、bar の title を指で下へ引くと窓が離れる（今までどおり）、menu の tap が開く。
