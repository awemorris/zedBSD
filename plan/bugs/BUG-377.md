# BUG-377: ZEDBSD_NOCT_ACCEL=y で emacs を選び libegl・libglesv2 を選ばない image で、/bin/noct が libEGL.so を要り emacs が起動しない

- 状態: fixed（2026-10-31 P7 q1768-i01、branch agent/p7-ws333b。config の解決と make -n で確かめた。image での emacs の起動は未実施）
- 発見: 2026-10-31 P2（q1761-i01、BUG-238 の QEMU の確かめの途中）。
- 症状: `ld.so: cannot open dependency`（libEGL.so）で emacs（noct の上の REmacs）が起動しない。noct の package が libEGL への依存を宣言していないので、config の選びで libegl・libglesv2 が入らない。
- 注意: noct の build の規則は toolchain の扱い（AGENTS.md §7）。直す時は Q1 の許可の範囲（依存の宣言だけ）で。
- 直す方針（案）: ZEDBSD_NOCT_ACCEL=y の時に libegl・libglesv2 を自動で選ぶ（menuconfig の依存）か、noct が libEGL を dlopen にして無ければ software に落ちる。

## 直し（2026-10-31 P7、q1768-i01）

- Q1 の許可の範囲（依存の宣言だけ。`userland/base/noct` の patch と build の規則は変えない）。
- `Makefile`（userland の依存の展開の前）: `ZEDBSD_ARCHITECTURE` が amd64 で `ZEDBSD_NOCT_ACCEL := y` の時、`USERLAND_noct_REQUIRE` に `desktop/libegl desktop/libglesv2` を足す。noct（と、それを要る emacs）を選ぶと 2 つの library とその依存（libvulkan・libwayland-client・libwayland-egl）が選ばれる。条件は noct の build の規則が accelerator を ON にする条件（amd64 と `ZEDBSD_NOCT_ACCEL=y`）に合わせた。
- `tools/menuconfig.py` の `normalize()`: 保存の時、amd64 で `ZEDBSD_NOCT_ACCEL` が y で noct を選んでいれば libegl・libglesv2 も選ぶ（生成の config.mk に明示される）。

## 確かめ（2026-10-31 P7）

config は `config/ci/config-amd64.mk` を include し `ZEDBSD_USER_PROGRAMS := cat emacs login sh` にした物（scratchpad、commit しない）。

| 確かめ | 結果 |
| --- | --- |
| make の解決（`--eval` で `ZEDBSD_USER_PROGRAMS` を出す）、amd64・accel=y | `emacs noct libegl libglesv2 libvulkan libwayland-client libwayland-egl` |
| 同、amd64・accel=n | `emacs noct`（足されない） |
| 同、amd64・accel=y・noct 無し | どれも選ばれない |
| 同、rpi4（arm64）・accel=y | `emacs noct`（足されない） |
| `make -n disk-image`、amd64・accel=y、直す前の Makefile（`git show HEAD:Makefile`） | `--file /bin/noct=…` は有り、`--file /lib/libEGL.so` は 0（不具合の再現） |
| 同、直した後 | `--file /lib/libEGL.so=…/dynamic/libEGL.so`・`--file /lib/libGLESv2.so=…/dynamic/libGLESv2.so`・`--file /bin/noct=…` |
| 同、accel=n | libEGL・libGLESv2 の行は無し |
| menuconfig の `save()`（emacs を選んだ値） | amd64・y: emacs noct libegl libglesv2 libvulkan libwayland-egl libwayland-client、amd64・n: emacs noct、rpi4・y: emacs noct |

- `make -n disk-image` の rc は 2（emacs の package の sub-make が `-n` で作られない work の directory に入れず止まる。dry run だけの事で、file の一覧はその前に出ている）。
- 未実施: image を作って emacs を起動すること（package の build が要るので作らない、Q1 の指示）。`plan/tools/menuconfig-target-host-test.py` は流したが、この直しと関係の無い所（firmware の既定の選び、amd-navi-firmware が増えた件）で rc 1 で止まり、noct の所まで進まない（既存の食い違い、Q1 に報告）。
