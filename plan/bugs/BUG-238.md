# BUG-238: base の emacs（REmacs）が `-nw` を受けない

Reproduction: reproduced（P2 の AAT の切り分け、QEMU、2026-10-06）
Disposition: scheduled（q799）
Discovery: q788（AAT の full の apps.emacs.edit-save、T1-202c）
Handling: `userland/base/emacs`（REmacs）

## 観測

AAT の `apps.emacs.edit-save` が `emacs -nw FILE` で失敗した。base の emacs（REmacs）には `-nw` の option が無い。GNU Emacs の利用者は端末で `emacs -nw` と打つ（WS124 の記録もベータ1 は「`emacs -nw` の端末版」）。

## 次

REmacs の引数の解析で `-nw`（と `--no-window-system`）を受けて無視する（端末版しか無いので意味は同じ）。`emacs --help` にも出す。host か guest で `emacs -nw FILE` が開くことを確かめ、AAT のシナリオは `emacs FILE` のままでよい。

## 2026-10-08 P2 の確認（q869）

- **未実装**: userland/base/emacs/src/main.c の引数の解析は `--script`・`--version` だけで、`-nw` は「remacs: unknown option」で exit 1。`--help` も無い。q799 は pending、commit 無し。
- AAT の `apps.emacs.edit-save` は `-nw` を付けない形に直して T1-232（2026-10-06）で pass。この Bug の証拠ではない。
- 残り: `-nw`・`--no-window-system` を受けて無視し、`--help` を出す。`emacs -nw FILE` が開くことの確認。
