# BUG-238: base の emacs（REmacs）が `-nw` を受けない

Reproduction: reproduced（P2 の AAT の切り分け、QEMU、2026-10-06）
Disposition: scheduled（q799）
Discovery: q788（AAT の full の apps.emacs.edit-save、T1-202c）
Handling: `userland/base/emacs`（REmacs）

## 観測

AAT の `apps.emacs.edit-save` が `emacs -nw FILE` で失敗した。base の emacs（REmacs）には `-nw` の option が無い。GNU Emacs の利用者は端末で `emacs -nw` と打つ（WS124 の記録もベータ1 は「`emacs -nw` の端末版」）。

## 次

REmacs の引数の解析で `-nw`（と `--no-window-system`）を受けて無視する（端末版しか無いので意味は同じ）。`emacs --help` にも出す。host か guest で `emacs -nw FILE` が開くことを確かめ、AAT のシナリオは `emacs FILE` のままでよい。

## 2026-10-08 P2 の確認（q869）

- **未実装**: userland/base/emacs/src/main.c の引数の解析は `--script`・`--version` だけで、`-nw` は「remacs: unknown option」で exit 1。`--help` も無い。q799 は pending、commit 無し。
- AAT の `apps.emacs.edit-save` は `-nw` を付けない形に直して T1-232（2026-10-06）で pass。この Bug の証拠ではない。
- 残り: `-nw`・`--no-window-system` を受けて無視し、`--help` を出す。`emacs -nw FILE` が開くことの確認。

## 修正（2026-10-08 P2、q870）

- 原因の訂正: zedBSD の `/bin/emacs` は `src/main.c`（host の CLI）でなく Noct の application（`remacs.nap`）で、引数は `editor/boot.noct` の `main(arg)` が受ける。今まで `arg[0]` をそのまま file にしていたので、`emacs -nw FILE` は `-nw` という buffer を開いた（T1-202c の観測どおり）。
- `userland/base/emacs/editor/boot.noct`: 新しい `remacsParseArgs` で、`-nw`・`--no-window-system` は受けて何も変えない。`--help` は使い方、`--version` は版を出して終わる。知らない option は「remacs: unknown option …」と使い方を出して終わる。最初の他の語を file にする。
  - Noct に exit の API が無いので、知らない option の時も `/bin/emacs` の終了の status は 0（main の戻り値は使われない）。
- `userland/base/emacs/src/main.c`（REmacs の C の launcher、host の CLI）も同じ option に揃えた（`parse_options`・`print_usage`）。ここでは status 1 で終わる。
  - この file は tree の Noct の header より新しい Noct を前提にしており、今の header では元からの `object_model` の誤りで compile できない（変更の前から）。新しい関数には誤りが出ない（`cc -fsyntax-only`）。
- AAT: `apps.emacs.edit-save`（helpers_apps.py・tests/scenarios/apps/emacs/edit-save.md）は `emacs -nw FILE` と打つ形に戻した（この Bug の回帰の試験）。check-scenarios PASS。
- 確認:
  - `make ZEDBSD_CONFIG=config/ci/config-amd64.mk BUILD=build/amd64 emacs`: rc 0（remacs.nap を作った）。
  - host の Noct で `remacs.nap` を動かした: `--help` は使い方、`--version` は「remacs 0.0.1」、`-nw` と `-nw /tmp/x.txt` は TTY の確かめまで進む（「(no tty)」、`-nw` は file にならない）、`--bogus` は unknown option と使い方。
- QEMU（T1 へ依頼）: AAT の `apps.emacs.edit-save`（`emacs -nw FILE` → 書いて C-x C-s → C-x C-c → file の中身）。
- Status: test-wait（T1）。
