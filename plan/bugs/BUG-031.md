Source: ws042-p009（q396-i01）の amd64 の boot test の画面（`build/boot-test-amd64-q396/login.png`・`login.txt`）。
Owner: none（未割当）
Queue: none。

## 期待と観測・影響

期待: kernel の message は 1 行ずつ、他の message と混ざらずに画面に出る。

観測（boot test が撮った画面。serial log ではない）: 画面の先頭の 3 行で、`usb-hid:` の行と `vfs:`（`sda partition ...`・interface の行）の行が文字ごとに交互に混ざった。

```
usb-hid: vevenfs: sda pt devicea rutsibt0i odne v1i cset=a2rt i=0000000nte0r:0fa
c0000800e=0 endpo data=000i00nt=81000:0 re0p00n0r8t0-0b ybtles=o8c
nterfacevfs:  sd0 ca plasasr t0i3t/i0o1n/ 012  dsrtarit=v0er00=u00s0b-h0id0:
```

2 回目: q402 の boot test（`build/boot-test-amd64-q402/login.png`、先頭の 5 行）。他の起動（q395・q397・q398・q399・q401 の boot test）では見ていない。二つの thread（CPU）が同時に console へ書き、行の単位の排他が無いように見える（未検証）。

影響: 起動時の message が読めなくなることがある。動作には影響しない（login prompt に届いた）。

## 調べたこと

- なし（記録だけ）。この Phase の変更（libedit の規約の書き直し）は kernel の出力と関係が無い。

## 再開の条件

kernel の console・log の出力を扱う WS で。受け入れ案: USB と storage の probe が並ぶ起動を 20 回撮って、行が混ざらない。
