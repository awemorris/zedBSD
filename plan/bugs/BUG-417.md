# BUG-417: ブラウザ: web platform の prelude の WebIDL の operation が constructor として呼べてしまう

- 状態: open（2026-11-02 17:16 Q1 が起票、P8 の報告から）
- 発見: 2026-11-02 P8（q1977、BUG-414 の test262 の調べ）。ECMAScript の組み込みの JS prelude（TypedArray・WeakRef・FinalizationRegistry）は object literal の method にして [[Construct]] と prototype を無くしたが、web platform の prelude（plan/ws074/phase230/prelude.js 約 2,939 行、phase232/net.js 約 678 行、`function` の約 546 か所）の WebIDL の operation は普通の関数のままで、`new` で呼べ、prototype を持つ。WebIDL では operation は constructor でない。
- 扱い: P8（ブラウザ）。大きい変更なので WS345 の後に。
