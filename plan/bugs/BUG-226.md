# BUG-226: 左の pane（Files・Mail・Calendar・Settings）で pointer の hover の描画が遅れる。CPU の合成の疑い、無ければ FPS の安定化

Reproduction: reproduced（ユーザー、実機 5330、2026-10-06 UAT）
Disposition: resolved（2026-10-08 夜 ユーザー「BUG-221, 226, 239はcloesします。」）

## 観測（ユーザー）

「Mailアプリの左ペインで、マウスポイントでポイント項目を変えるときに描画が遅れます。Filesでのドラッグ範囲選択と同じで、FPS維持の仕組みがあるといいと思いましたが、それ以前に、何かGPU描画でない合成とかをやっている気がしました。コマンドバッファの作成だけでこんなに遅いか？と疑問に思ったので、たぶん選択色を背景にしたアイコン画像をCPUで生成していたり、類似の計算があるのではないでしょうか？もしそういったことをしていなくて純粋にGPUが遅いなら、FPS安定化で回避するしかないですが。左ペインのあるFiles,Mail, Calendar,Settings、すべて修正対象です。」

## q866（P1、2026-10-08）: Mail・Calendar の hover の部分の再描画

ws090-p018 の q791-i01 で Settings・Files の hover は部分の再描画にした。Mail・Calendar（kl_ui の app）は hover が変わる時だけ frame を描く所まで（全体）だった。

### 原因（host で測った）

- Mail（1180x740、-O2、glass）の hover の 1 frame は約 2.1 ms。perf（sudo）: `canvas_blend_premultiplied` 33%・`kl_canvas_fill` 18%・`canvas_blend` 14%、
  文字の glyph 7%（cache から）、icon の rasterize は無い。ユーザーの疑った「icon を CPU で作り直す」は無く、**hover のたびに窓の全体の半透明の塗り（panel・行の地）を
  画素ごとに合成し直していた**のが時間の大半。`kl_canvas_fill` は画素ごとに色を premultiply し直していた。
- 5330 の -Os ではこの数倍、さらに present（全画面の写しと Vulkan）が毎 frame 掛かる（BUG-221 の記録）。

### 修正

- libkeiland（KL_VERSION 62）: `kl_ui_take_damage(ui, rect)` — `kl_ui_pointer_motion`・`kl_ui_pointer_leave` で lit の widget が変わった時、前と今の widget の領域
  （表示中の frame の hit の矩形 ＋ 8 px）を集め、app に渡す（領域の分からない widget の時は窓の全体）。`kl_ui_begin` で消える。
- `kl_canvas_clear` は clip の中だけを消す（clip を push しない今までの呼び出しは全体のまま）。
- `kl_canvas_fill` は色を 1 回だけ premultiply し、不透明は直接書く（結果は前と同じ: 古い canvas.c と 20 万回の乱数の fill で byte 一致を確かめた）。
- Mail（`mailer/main.c`）・Calendar（`calendar/main.c`）: hover だけが変わった frame は `kl_ui_take_damage` の part を clip にして描く（他の変化・drag・動きの間・
  Calendar の机の animation の間は全体）。
- 同じ測定で: hover の frame 約 0.46 ms（全体は 1.86 ms、fill の直しで 2.07 から）。

### 確認

- host: `plan/ws169/tests/run-host-mailer.sh` に `hover-part`（60 回の移動、opaque と glass、部分の frame と全体の frame が画素で同じ）: PASS（各 20 回の部分）、他の check も全て PASS。
  `plan/ws155/tests/run-host-calendar.sh` PASS、`plan/ws090/tests/host-input.sh` 96/96、`host-widgets.sh` 94/94、`plan/ws094/tests/host-desktop.sh` PASS。
- build: zedBSD の mailer・calendar・phone・files・wayland、keiland-linux の gcc・clang で warning 0。style-check 新しい指摘 0。
- QEMU（T1 へ）: Mail・Calendar で左の pane の行の上を pointer で動かし、行の光りが pointer に付いてくること・跡が残らないことを画面で確かめる（下の依頼）。
- 未実施: 5330 の体感（ユーザー）。Phone・Music・Photos は対象外（同じ口で直せる）。
