# BUG-376: PS/2 の mouse の port（aux）が、mouse が無いのに node を作り、open のたびに約 80 ms 待って EIO を返す

- 状態: open（2026-10-31 登録、P6 が直す）
- 発見: 以前の調べ（master.md の未決に残っていた物）。kernel の PS/2 の driver（src/kern/platform/pcat.c の drv_pcat_ps2_8042_init の辺り）。
- 影響: mouse の無い機械で、input の device を開く program（compositor など）が、open のたびに約 80 ms 待たされる。
- 直す方針（案）: 8042 の aux の port の存在を初期化の時に一度だけ確かめ（aux の test の command と、mouse の reset への応答）、無ければ node を作らない。あれば今どおり。
- 2026-10-31 ユーザーから、PS/2 の aux は Bug の ticket を起票してどこでもいいので割り当てる、という趣旨の指示を受けた。
