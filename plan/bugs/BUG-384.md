# BUG-384: arm64 の kernel の Image の header の image_size が BSS を含まない（arm64 の boot の約束に反する）

- 状態: open（2026-11-01 03:37 Q1 が起票、Pi 5 の黒い画面の解析（bug-analyzer）の副次の発見）
- 中身: Pi 5 の kernel（tree fba292f54）で、header の image_size は 0x409000 だが、BSS は 0x489000 から 0x6f8ac0 まで。Linux の arm64 の boot の約束は
  image_size が BSS を含む全体の大きさであること（boot loader がその範囲に他の物（DTB・initrd）を置かないため）。
- 影響: 今は DTB が 0x2efec600 に置かれ重ならないので症状は無い。boot loader が kernel の直後に DTB などを置くと BSS の初期化で壊れ得る。Pi 4・Pi 5・ODROID-C5 など arm64 の全部。
- 直す方針（案）: link の script で image_size を BSS の終わりまでにする。
