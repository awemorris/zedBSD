# BUG-425: Raspberry Pi 500（と Pi 5）の設定アプリに有線 LAN の項目が出ない

- 状態: closed（2026-11-13 Q1。今の main の Pi 5 で再現せず、設定の Network・Ethernet の page に en0 が出る。radio のある機械の初期設定の network の段は Wi-Fi の page だけを出す設計で、報告はそこを見た見込み）
- 発見: 2026-11-13 外部の利用者の Raspberry Pi 500（BCM2712 D0、8 GB）での報告（source c4cede8、2026-11-03）。
- 起きた事: en0 は ifconfig で 1000 Mbps・DHCP で動いているが、設定アプリの network に有線の項目が出ない。
- 確かめ: 今の main の rpi5 の image で再現するか（Pi 5 の実機、10.0.30.5）。再現しなければ、直した commit を探して記録し閉じる。

## 2026-11-13 P1 の確かめ（q2042-i01）: 再現せず

- 板: Pi 5（10.0.30.5、`uname -sm` が `zedBSD aarch64`）。userland は 2026-11-12 22:30 頃の main の image（`/bin/settings` は main 868de90ce8 の build と cksum 一致 2228730128）。kernel・`/bin/wayland`・`/lib/libkeiland.so` を main（f949ade4f2 の tree）の試験の build（入力の注入と画面の capture 付き）に替えて起動し、`keiland-shot` で画面を撮った（試験の後に元へ戻した: vmunix cksum 3179780313、wayland 2828746679、libkeiland 2184013129）。
- 結果: 有線は全部の所に出た。設定の Home の Ethernet（Connected · en0）と sidebar の Ethernet、Network の page の「Ethernet / LAN」の card（Ethernet (en0)、Connected、10.0.30.5、Details）と Connection Status の Wired、Ethernet の page（en0 の状態・速度・address・DHCP・IPv6）。screenshot は worktree の `build/review/p1-pi500/10-apps.png`・`11-network.png`・`12-ethernet.png`。
- 直した commit: 無い。`userland/desktop/settings/`、`userland/desktop/libkeiland/`（網の link の一覧）、`userland/desktop/libkeiland-backend-zedbsd/network-link-zedbsd.c`（無線かどうかの判定）、kernel の `src/kern/net/inet-socket.c`・`wifi/wlan.c` は、報告の source（c4cede8）から main まで Makefile の他は変わっていない（`git log c4cede8..main -- <path>`）。
- 見込み: radio のある機械では、初期設定のウィザードの network の段は Wi-Fi の page だけを出す（`welcome.c` の `welcome_page`。radio が無い時だけ Ethernet の page）。その段の画面（`build/review/p1-pi500/02-wiz2.png`）には有線の項目が無いので、報告はこの段を見た可能性が高い。
- 閉じる案: 「再現せず、設計どおり」として閉じる。ウィザードの network の段に有線の状態も出すかは製品の判断（必要なら別の WS）。
