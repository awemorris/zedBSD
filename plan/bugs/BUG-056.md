## 期待と観測

期待: 壁紙に wl_shm の窓 2 つと terminal の窓が出て、ドッキング・Wiseview・閉じるで画面が変わる。

観測: capture の 5 枚が同じ画面（壁紙とバーだけ、窓無し。`build/ws035-p068/hw1/`）。検査は desktop_drawn だけ PASS、
dock・wiseview・close は FAIL（画面が変わらない）。guest の log は wltest が殺された直後（`WLKILL status=124`）までしか disk に無く
（その後の sync が無く、guest は QEMU の timeout で止まった）、wl_shm の client の接続も terminal の起動も記録が無い。

## 調べたこと

- image の中身は正しい（`ufs-cat` で `/etc/zdesktop/run-mview.sh` が terminal の script、font と `/bin/zdesktop-terminal` がある）。
- 同じ image の組み立てで次の run（`hw2`、log を 2 秒ごとに sync する版）は 6 検査 PASS、terminal は START・RESIZE・DONE。
- 以前の mview の run（p067・p050）で同じ症状は無い。

## 再調査の条件

同じ症状（capture が変わらない、窓が出ない）が再び出たとき。そのときは guest の log が sync されていること（`run-terminal.sh` の
2 秒ごとの sync と dmesg）を確かめ、zwl の最後の frame と kernel の GPU の hang の有無を見る。

## 追記（2026-09-26、ws068-p006 の実機の run、`CAPTURE=zdesktop-x11 ZDESKTOP_APP=home`）

- run1（build/ws068-p006-hw-run1/）と run3（build/ws068-p006-hw-run3/）で同じ症状。run2 は同じ image の組み立てで通った。
- run3 は dmesg が sync されていた: `ZWL CLEANUP client=1`（wlkill が 1 つ目の wl_shm の client を止めた後の後片付け）の直後に
  `i915: capture: the lease owner closed without releasing it` / `lease 1 released after 128 frame(s)`、その後 `gpu: ioctl G2 -> error 13` が続く。
  zwl の stdout は行 buffer（main.c の setvbuf）なのに `ZWL EXIT` が無い → **zwl が client の後片付け（`zwl_client_destroy`）の中か直後に
  signal で落ちている**（GPU の fd が閉じて lease が外れた）。Venus（wl_shm の copy の道）では同じ後片付けで落ちない。
  i915 では client の buffer が GPU の画像の import（`ZWL VULKAN_IMPORT`）なので、import の破棄と compose の quiesce の間を疑う。
- 次の調べ: zwl を gdb 無しで調べるには、落ちたときの signal と PC を kernel の log に出す（kernel 側の変更が要る）か、
  `zwl_client_destroy` の段ごとの log（sync 付き）を出す。

## 追記（2026-09-27、ws068-p006 の続きの実機の run）

- 17 run 中 3 回（log は scratch に保存、代表は run の k・q・x）: `ZWL CLEANUP client=1`（と client=2）の直後に
  `ZWL EXIT frames=... error=5 cleanup_failed=1`。**zwl は signal で落ちたのではなく、`server->failed` が立って正常に終わっている**
  （前の追記の「signal で落ちている」は、stdout に EXIT が出る前に log の sync が止まっていたための誤読）。
- `server->failed` を log 無しに立てていた場所（compose の完了・描画、surface の破棄での unscan、buffer の hold の不整合）に
  `ZWL FAILED site=...` を足した。次に出たとき、どこで失敗したかが分かる。
