# BUG-264: login の後に現れた入力の device（USB・Bluetooth）の node を compositor が開けない疑い

- 状態: unknown（読みだけ） / scheduled
- 発見: 2026-10-08 P2 の ws143-p005 の設計（Q23）の読み。
- 観察（読み）: sessiond は login の時にある `/dev/input/event*` だけを seat の利用者へ chown し、hotplug を聞かない。login の後に挿した USB のキーボード・マウスや、Bluetooth で繋いだ HID の node は root のままで、利用者の compositor が開けない見込み。あわせて compositor の KWL_INPUT_MAX は 16。
- 期待: login の後に現れた入力の device も、seat の利用者の compositor が使える。
- 関係: WS143 p005（Bluetooth の HID）、WS132（PnP の通知）。

## 次

- QEMU で login の後に device_add usb-kbd をして、node の持ち主と compositor の log（開けたか）を確かめる（再現）。
- 直し: sessiond が /dev/system の PnP の事象（WS132）を聞いて新しい event* を seat の利用者へ chown する。KWL_INPUT_MAX の上限も見直す。
