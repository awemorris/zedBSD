# BUG-041: NVMe の volume の mount が ETIMEDOUT で失敗することがある

Bug ID: `BUG-041`
Reproduction: reproduced（QEMU、amd64 guest、間欠、1 回）
Disposition: tracking
Date: 2026-09-25
Source: ws054-p004（q416-i01）で、2 台の NVMe の volume（`-device nvme`）をつないだ guest の起動の直後に `mount -t ufs /dev/nvme0n1 /work` したとき。
Owner: none（未割当）
Queue: none。

## 期待と観測・影響

期待: 起動の直後の mount が成功する。

観測: `mount: nvme0n1 on /work: Connection timed out`。同じ構成の他の起動（q414〜q416 で 10 回以上）では成功した。
失敗した起動の kernel の message は取れていない（その場で guest を止めた）。NVMe の driver の timeout は 7500 ms（`nvme: PCI controller ... timeout=7500ms`）。

影響: NVMe の disk を使う試験が稀に最初の mount で失敗する。再起動で直る。

## 再開の条件

NVMe の driver を扱う WS で。次に起きたら `dmesg` の nvme の行を取る。受け入れ案: 2 台の NVMe をつないだ起動を 20 回して全て mount できる。
