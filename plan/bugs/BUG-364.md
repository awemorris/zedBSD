# BUG-364: gpu_fence_get の foreign の fence が device を比べず、別の GPU の fence を承認なしに受ける

- 状態: open（2026-10-30 Q1 が登録）
- 発見: 2026-10-30 WS009 p015・p023（DOC-54 の文書の担当、source の読み）。
- 場所: `src/drivers/gpu/gpu.c` の `gpu_fence_get`（foreign=1）。`gpu_dependency_ioctl`（`GPU_DISPLAY_PRESENT_SYNC` の wait_fd）と `gpu_commit_ioctl`（plane の wait_fd）から届く。comment は「approved companion GPU」と書くが、承認（companion の組）の確かめが無い。signal_fd は比べている。
- 影響: どの GPU の fence でも display の待ちに使える。待ちの意味は保たれる見込みだが、設計の約束（承認した相方だけ）と食い違う。未確かめ（実機・QEMU で再現していない）。
- 直す方針: companion の組（roles・companion_id）を確かめるか、どの GPU の fence も受ける設計なら comment と gpu-display.h を直す。どちらかは直す担当が設計の文書（master-design-policy・gpu の設計）を見て決め、決まらなければ Q1 に返す。
- 文書: docs/reference/gpu-fences.md は今の動き（device を比べない）を書いている。直したら文書も合わせる。
