# BUG-397: Windows 版ブラウザ: Google の頁の「サイト」の link を click すると app が固まって応答しなくなる

- 状態: open（2026-11-02 06:16 Q1 が起票、P4 q1915）
- 発見: 2026-11-02 06:16 ユーザーの Windows での OmniGrammaton（WS334 の Windows 版ブラウザ）の UAT。
- 中身: 起動すると Google の top が出る（ユーザーの評価はよい）。その頁の「サイト」の link を click すると、その場で app が固まり応答しなくなる。link の遷移で固まるので、libbrowser の navigation か Windows の shell の message loop が疑わしい。
- 扱い: P4（q1915）。このセッションで直す（ユーザーの指示）。描画と JavaScript の全般の改善はクラウドのセッションの libbrowser を待つが、この Bug はこのセッションで直す。
