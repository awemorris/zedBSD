# BUG-221: Files と desktop の drag の範囲選択が pointer に遅れて追従する（再描画を一定の frame rate（15〜30 fps）に丸める）

Reproduction: reproduced（ユーザー、実機 5330、2026-10-06 UAT）
Disposition: tracking
Discovery: 2026-10-06 ユーザーの UAT のコメント
Handling: WS127・WS099

## 観測（ユーザー）

「Filesやデスクトップで、ドラッグで範囲選択すると、やや遅れてマウスに追従します。マウス移動イベントすべてで再描画していることがインタラクションの遅れの原因だと思いますが、これは概ね一定のフレームレートに丸めてアニメーションするのが、レスポンス向上するので、よさそうです。そんなにヌルヌルのアニメでなくていいと思うので、30fpか15fpsでいいと思います。」

## 次（未確認の見込み）

pointer の移動の event ごとの再描画をやめ、最新の位置で一定の間隔（30 fps、重ければ 15 fps）に描く。
