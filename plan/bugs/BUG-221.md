# BUG-221: Files と desktop の drag の範囲選択が pointer に遅れて追従する（再描画を一定の frame rate（15〜30 fps）に丸める）

Reproduction: reproduced（ユーザー、実機 5330、2026-10-06 UAT）
Disposition: scheduled（q866、P1、2026-10-08: desktop の範囲選択を直した。QEMU は T1 待ち）
Discovery: 2026-10-06 ユーザーの UAT のコメント
Handling: WS127・WS099

## 観測（ユーザー）

「Filesやデスクトップで、ドラッグで範囲選択すると、やや遅れてマウスに追従します。マウス移動イベントすべてで再描画していることがインタラクションの遅れの原因だと思いますが、これは概ね一定のフレームレートに丸めてアニメーションするのが、レスポンス向上するので、よさそうです。そんなにヌルヌルのアニメでなくていいと思うので、30fpか15fpsでいいと思います。」

## 次（未確認の見込み）

pointer の移動の event ごとの再描画をやめ、最新の位置で一定の間隔（30 fps、重ければ 15 fps）に描く。

## q866（P1、2026-10-08）: desktop の範囲選択

ws090-p018 の q791-i01 で Files の窓（範囲選択・hover）は部分の再描画にした（T1-233 (b) PASS）。残っていた desktop（`files --desktop`、`ui-desktop.c`）を直した。

### 原因（読んで host で測った）

- Files の loop は 1 回の dispatch で溜まった event を全て受けてから 1 frame を描く（pointer の event ごとではない）。frame の間隔は描画と present の時間で決まる。
- desktop は rubber band がある間「上に何かある」（`desktop_over`）扱いで、ws094-p009 の「変わった cell だけ」の再描画を使わず、移動のたびに output の全体
  （5330 は 1920x1200 前後）を消して全ての icon と band を描き直していた。
- host の測定（`files --desktop` の描画、30 項目、1920x1152、-O2、40 回の移動で band が icon の列を横切り戻る）: 移動 1 回の描画 平均 4.74 ms・最大 6.17 ms。
- 実機の frame の残り: ws094-p009 の 5330 の記録で、click の選択の frame（90 ms）の大半は Vulkan の呼び出し（submit 32〜51、present 4〜51、fence 1〜11 ms）。
  これは描画を軽くしても残る（libkeiland の present は毎 frame 全体の画素を写して全画面の quad を描き、fence を待つ）。

### 修正

- `ui-desktop.c`: 保持した frame が band だけを上に持つ時も部分の再描画にする（`desktop_over_band`）。band は前の band と今の band の矩形から、両方の中（縁の
  2 px を除く）を引いた所だけを消して描き直す（`desktop_band_partial`・`desktop_band_region`・`desktop_redraw_rect`、その中の icon と band を clip して）。選択の変わった
  cell は前と同じく cell ごとに描き直し、band を cell の中に重ねる。保持した frame に band とその矩形を記録する（`files.h` の `painted_band`・`painted_band_rect`）。
- `main.c`: band の間の frame の数・平均・最長・描画・present の最長を band の終わりに 1 行（`DESKTOP band frames= mean_ms= longest_ms= draw_ms= present_ms=`）。
  実機で frame の時間がどこに行くかを見るため。
- 同じ測定で: 移動 1 回の描画 平均 1.10 ms・最大 3.00 ms（band が icon を横切って選択が変わる間を含む）。5 回ごとに全体の再描画と画素を比べて全て同じ。

  （角の印が残る）で、全体の再描画と画素が同じ。`host-desktop.sh` は host-build.sh が今回作った object だけを link するようにした（worktree に古い名前の object が残ると
