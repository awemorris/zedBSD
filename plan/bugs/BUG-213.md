# BUG-213: ue0 の link down の後に interface が残ると Settings に「Status No address」と出るのに IP address も表示される

Reproduction: reproduced（ユーザー、実機 5330、2026-10-06 UAT）
Disposition: tracking
Discovery: 2026-10-06 ユーザーの UAT のコメント
Handling: WS089（Settings の Network）・networkd

## 観測（ユーザー）

「ue0はリンクダウンしたあともインタフェースは残っている状態にすると、SettingsでStatus No addressと表示され、でもIPアドレスが表示されています。」

## 次（未確認の見込み）

link down の時に address を消すか、表示を状態に合わせる。

## q780-i01（P1、2026-10-06）: 直し

Status: test-wait（T1 依頼中）

原因: networkd は有線の cable が抜けると `ifconfig IF down` と default route の撤回をするが、IPv4 address を残し、さらに USB の adapter が次の cable を
報告できるよう interface をすぐ up し直す（`NETWORKD_LAN_ACTION_RAISE`）。Settings の Ethernet の card は「up で running でない」を「No address」と書き、
残った address も出していた。

直し（e2d6099b）:
- `userland/base/networkd/main.c` `lan_take_down` → `lan_clear_address`: netmask（subnet の route が消える）・broadcast・address を 0 に。次の cable で
  DHCP・static の設定が付け直す。
- `userland/desktop/settings/page-network.c` `network_link_card` の Status: running と address = Connected、running だけ = No address、up で cable 無し =
  **No cable**、down = Down。

確認: build（networkd・settings）warning 0。host の描画（`plan/ws089/tests/host-build.sh`、新しい scenario `--network=nocable`）で Status「No cable」・
IPv4「-」を確認。QEMU: `plan/ws033/tests/lan-link-down.sh`（usb-net の set_link で cable を抜き、address と subnet の route が消えること）を T1 に依頼。
実機: 次の UAT。

## 2026-10-08 P2 の確認（q869）

- 実装済み（e2d6099b）: settings/page-network.c で Status を Connected・No address・No cable・Down に分け、networkd の `lan_clear_address` で address を消す。
- host: 描画で「No cable」と IPv4「-」を確認（ticket の記録）。
- QEMU: T1-222（2026-10-06）settings-p022 PASS（接続中の card）。cable を抜いた状態は QEMU で未確認（carrier の事象が無い）。
- 残り: 実機の UAT だけ（ue0 を抜いて Status が No cable、address が出ない）。
