# BUG-248: Text Editor のメニューが他の app と違う独自の形（下線の付いた共通のメニューに）

- 状態: reproduced（ユーザーの UAT、2026-10-07） / resolved（2026-10-07 fef7afcd4、T1-360 QEMU PASS: 下線の File・Edit・View・Help、`TEXTEDIT TITLEBAR` 0 行、Find の panel の開閉。実機はユーザーの UAT）
- 発見: 2026-10-07 ユーザーの UAT

## 観察（ユーザーの文）

「Text Editorのメニューがアドホックすぎます。ほかのアプリと同じように、下線のあるメニューで作ってほしいです。」

## 次

- `userland/desktop/textedit` のメニューを、他の app（Files・Settings・Notes など）と同じ libkeiland の共通のメニュー（accelerator の下線の付いた menu bar）で作り直す。項目と短縮 key は今の物を保つ。試験は master の Tools の Text Editor の試験（plan/tools/textedit）を追従させる。

## 原因（2026-10-07 P2）

Text Editor は title bar の presentation に controls（`titlebar.c` の `kl_window_set_controls`: Open・Save・Undo・Redo の button と Find の欄）を出していた。zdesktop は controls の窓には menu bar を描かない（`titlebar-shell.c` の `kwl_titlebar_draw`: menu の mode の時だけ `kwl_menu_draw_bar`、下線付きの File・Edit・View・Help）。menu の表（`menu.c`）は他の app と同じ libkeiland の System Menu で作ってあったが、title bar には出ず、F10 と短縮 key でしか届かなかった。Notes・Terminal・Calendar などは controls を出さず、menu bar が出る。

## 修正（2026-10-07 P2）

- `main.c`: title bar の controls を出さない（`te_titlebar_*` の呼び出しを全部外す）→ zdesktop は既定の menu の mode で、他の app と同じ下線の付いた menu bar（File・Edit・View・Help）を title bar（docked の時は system bar）に描く。menu の項目と短縮 key（`menu.c` の表）は変えていない。
- Find（Edit > Find...、Ctrl+F）は title bar の欄の代わりに、Replace の panel と同じ形の窓の中の panel（`TE_DIALOG_FIND`、`main_find_panel`）: 欄（選択か前の検索の文字で始まる）、打つと最初の場所が選ばれ、Next（Enter）・Previous・Done（Esc）。Find Next（Ctrl+G）・Find Previous（Ctrl+Shift+G）は panel が開いていても効く。log `TEXTEDIT FIND open find=…`・`TEXTEDIT FIND closed`。
- `app.c`: `te_app_find_text`・`te_app_find_close`、`panel_fresh`（旧 `replace_fresh`）。title bar の欄の事象（`TE_EVENT_FIND_TEXT`・`TE_EVENT_FIND_DONE`、`TE_FIND_*`、`te_host.find_focus`）を削除。
- `window.h`・`Makefile`・`Makefile.linux`・`Makefile.freebsd`: `titlebar.c` を外した。`userland/desktop/textedit/titlebar.c` は使われていないので削除を Q1 に依頼。
- 試験: `plan/tools/textedit/host-core.c` に Find の panel の 5 件（開く・打つと見つかる・Find Next は通る・他の action は待つ・閉じる）、`tests/scenarios/apps/textedit/menu-bar.md`（AAT の新しいシナリオ: menu bar の `KWL MENU bar … item=1〜4`、F10、Find・Replace の panel、Ctrl+S）。
