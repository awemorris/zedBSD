# BUG-283: ロック画面の Password と Security Key の button の高さが小さい

Reproduction: reproduced（ユーザー、実機 5330、2026-10-10 UAT）
Disposition: resolved（2026-10-10 ユーザーの 5330 の UAT「ロック画面の buttonでPIN と鍵を登録した状態で lock すると、PIN、鍵、両方ともロック解除できました。Closeします」）
Discovery: 2026-10-10 ユーザーの 5330 の UAT
Handling: WS187（ロック画面）・ws172-p007（方式の pill）

## 観測（ユーザー）

「ロック画面のPasswordとSecurity Keyのボタンが高さが小さいので、外側の時計の下のボックスを下に広げるなどして改善してほしいです。」

## 直し（2026-10-10、P1、agent/p1）

- `userland/desktop/wayland/greeter.c`: 方式の選択（Password・PIN・Security Key の pill）が出る時（sessiond が password 以外を出す時）だけ、その行の高さを 28 → 40 px（`GREETER_STYLE_HEIGHT`）、その下の card の余白を 4 → 20 px（`GREETER_STYLE_MARGIN`）にした。card の上端は方式の無い時の高さで決め（`base_height`）、増えた分は**下へ**広がる（時計の位置 `kwl_lock_clock_layout` は card の上端で決まるので動かない）。pill の文字は行の中央（`rect[1] + rect[3] / 2 + 5`、28 px の時の 19 と同じ）。方式の無い時の配置は今と同じ。
- 確かめ: compositor（`build/p1-uat/bin/wayland`、current-uat）の build rc 0・warning 0、style-check 0（変更の前と同じ）。host の試験は無い（描画）。
- 未実施: T1 の AAT（`desktop.lock.swipe-card` を PIN の登録のある利用者で流し、card の pill の行の PNG を撮る。log の `KWL GREETER link … height=40`）、5330 の UAT。

## 2026-10-10 QEMU（T1）

T1-521 で pill の高さ 40 と scenario の pass（PASS）。実機は次の UAT。

## 2026-10-10 close（ユーザーの UAT）

「ロック画面の buttonでPIN と鍵を登録した状態で lock すると、PIN、鍵、両方ともロック解除できました。Closeします」
