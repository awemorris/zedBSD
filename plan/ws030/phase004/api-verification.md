# Vulkan 1.0 / direct-display API の実装・検証台帳

対象は全137 core commandと、Vulkan 1.0に適用する `VK_KHR_surface` / `VK_KHR_display` / `VK_KHR_swapchain` / `VK_KHR_display_swapchain` の18 command。155行は公開宣言、dispatch台帳、実装定義と一対一で照合した。これは内部受け入れ資料であり、Khronos CTS合格・正式適合認証の宣言ではない。

全行共通: `libc/include/vulkan/vulkan_core.h` に宣言し、`dispatch-table.inc` と ELF version script に登録する。ABI試験は公式の固定参照headerに対してi386/amd64の122構造体、842 field配置、2348定数を照合する。dispatch試験は実装18 familyを結合し、155 symbolとglobal/instance/device、拡張enable・support条件を独立に確認する。行の試験列は、そのAPIを含むfamilyの意味論試験を指す。すべての有効入力組合せを実GPUで実行したという意味ではない。

実装ファイルは `userland/base/libvulkan/`、試験ファイルは `plan/ws030/tests/` を基準とする。Uが標準Vulkanのhandle・codec・所有権・WSIを担当し、Kは汎用のGPU session/resource/map/submit/displayと権限・寿命を担当する。155個の専用ioctlを増設しない。

## 共通機構とK境界

`libvulkan-foundation.c` は実object/wire/allocatorを使って4096個の動的objectと4thread、寿命・ID・byte orderを確認する。`libvulkan-context.c` はsmall command、80KiB shared command、8KiB返信、破損返信と停止時計を確認する。`wsi-native.c` は実際のU側 ioctl adapterのlayout・lease共有・queue間present予約を確認する。

`gpu-display.c` は実K coreを通し、read/write権限、全6 display操作の入力検証、foreign lease/handle、claim copyout失敗回収、完了sequenceを確認する。既存 `plan/ws014/tests/gpu-framework.c` は実resource table、96 resources、mapping後のfd close、範囲・mprotect・fork後の参照寿命を確認する。`vmspace-device.c` は実VM関数とdevice backing、`pci-device-cache.c` は実PCI/K cache属性契約、`amd64-device-map.c` は承認済みHAL差分を確認する。各試験でmock化した境界と実装を含めた範囲は、runnerとfixture冒頭に記す。

## 最終統合受け入れ

`q308-lifecycle-003` は全6枚の実VNC/GPU readback/独立oracle、通常再起動、SIGINT異常終了後の再起動、640×480 console復帰とechoによる画面更新、別processの表示競合拒否とowner35frame完走を通過した。最終buildと実行済みkernel/appはbyte一致する。詳細は [q308実行結果](../results-q308.md)、[能力・limits監査](capabilities.md)、[最終証拠](final-evidence/verification.json) を参照する。

`text-snapshot.c` / `venus-console.c` は実文字renderer・console workerの所有権とkernel表示資源を確認する。live MMIOをアクセス禁止にしたsnapshot、native/legacy所有中の更新抑制、解放後の復帰、query状態、失敗時の保持・stop/reapを通常・ASan/UBSanで検証した。kernel_putcの登録も共通文字出力を通りgenerationを更新する。

先行試行で判明したoracle条件、PCI cache引数、console復帰と検証設定・診断名の不足を修正し、失敗履歴を保持した。全optional featureの全組合せ・全limitの実機実測や正式CTS認証を意味しない。
