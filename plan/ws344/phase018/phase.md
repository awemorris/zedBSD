## 3. 試験の項目

- yuv_pixel: (16,128,128)、(235,128,128)、(81,90,240)、(0,0,0)、(255,255,255) を output.h の式で手計算（clip の両端を含む）。
- premultiply: 全ての x・a（0〜255）で (x * a) / 255（a 255 は x）。
- from_yuv: 3x3 と 4x2 と 1x1 の画像の chroma（2x2・2x1・1x1）で fancy の各画素を手で（近い sample・横・縦・斜めの選び方、端の clamp）、no_fancy、alpha NULL → 255、alpha の stride、premultiply、全ての layout（RGB・RGBA・BGR・BGRA・ARGB と premultiply）の byte の位置、flip（負の row_step）、row の padding を書かない。
- from_argb: 全 layout、premultiply、flip。
- 期待は式から手で。dwebp との一致は p019 の compare で。
- 全ての単体試験は ASan・UBSan で落ちず（run-unit.sh）、途中で切れた入力・範囲の外の値・乱数の入力で決められた誤りを返す。
- 期待の値は仕様の表・式と手の計算、test の側の逆の処理（lbitwriter・boolwriter で組んだ入力）だけから作る。他の実装の出力を期待の値にしない（fixture の全体の試験は道具が libwebp の出力と比べる）。

## 4. 注意

- fancy の近傍: x が偶数なら左（i − 1）、奇数なら右（i + 1）。y も同じ。添字は plane の中に clamp。
- 値は (9 * near + 3 * horizontal + 3 * vertical + diagonal + 8) >> 4。
- 定数の block に「Values referenced: libwebp 1.5.0 src/dsp/yuv.h (BSD-3-Clause), the default YUV to RGB constants」、fancy の規則の block に「Procedure referenced: libwebp 1.5.0 default (fancy) upsampling, the 9-3-3-1 weights as output.h states them」（ws.md の「Q1 の判断」1）。
