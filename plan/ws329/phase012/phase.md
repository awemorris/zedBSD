## 試験の項目

- SAD・SSD: 手で計算した 4x4・16x16 の例と、乱数の block での素朴な二重 loop（試験の中）との一致。SATD: 手で計算した 4x4 の Hadamard の例（平ら・1 画素・市松）、8x8・16x16 は 4x4 の和。
- λ: header の確かめの値（sad[12] = 236、ssd[12] = 218）と、試験の中で式から計算した全 52 の値と一致。`h264enc_cost` の飽和。
- mvd の bit: 0・±1・±2・±3・大きな値で se(v) の長さ。
- source: I420 と NV12（chroma の分け）の copy、176x144（MB の倍数）と 170x130 相当の偶数の大きさ（右と下の端の繰り返し）、stride の大きい入力、EINVAL の入力。
- 共通: 誤りの引数で落ちず header の誤りを返す。ASan・UBSan の報告 0。期待の値は仕様の表・手の計算・decoder の module の読み戻し（design §10.1）から作り、他の encoder（x264・openh264・JM など）の出力や source を使わない。
