## 3. 試験の項目

期待の値は仕様の表・式・試験の vector と手の計算、`plan/ws336/tests/unit/wire.h` で組んだ bytes だけから作る。他の実装の出力を期待の値にしない（host の OpenSSH との相互運用は別の確かめで、期待の値の生成ではない）。

- 各 parser 100 万回以上（host の時間で 30 分以内）
- monitor: 乗っ取られた pre-auth を模した request の列（他の user の署名 data、2 回目の SIGN、AUTH_DONE の偽の state）で、許可が出ない事
- 時間の差: 存在する user と存在しない user、正しい password と違う password の応答の時間の差が 50 ms 未満
