### BUG-017 related observation: q199 boot-media ordering

`ws025/temp/q199-super2/guest.log` publishes SuperSpeed UAS
`sda`, then reports VFS initialization failed (6), and only afterwards publishes
the boot BOT disk `sdb`. This is a boot-media wait/order observation; a shared
root cause with the original enumeration error is unproven. With boot BOT on
xHCI port 1 and UAS on port 2, `q199-super3` boots and passes UAS lifecycle I/O.
Preserve both topologies when investigating; the passing order is no general fix.
