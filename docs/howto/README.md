# How-to guides

Status: current navigation index

How-to guides are reproducible, task-oriented procedures. They state supported
architectures and prerequisites, use non-destructive examples by default, and
include both the expected success observation and a diagnostic path.

## Guides

- [Boot, root storage and installation status](boot-and-storage.md): disposable
  boot, root modes, USB evidence and unfinished installer boundary.

- [Build zedBSD from source](build-from-source.md): host prerequisites,
  toolchain bootstrap, target selection, parallel image builds, QEMU launch,
  and common failures.
