# How-to guides

Status: current navigation index

How-to guides are reproducible, task-oriented procedures. They state supported
architectures and prerequisites, use non-destructive examples by default, and
include both the expected success observation and a diagnostic path.

## Guides

- [Boot, root storage and installation](boot-and-storage.md): disposable
  boot, root modes, and installing amd64 UEFI PCs with the graphical installer.

- [Build zedBSD from source](build-from-source.md): host prerequisites,
  toolchain bootstrap, target selection, parallel image builds, QEMU launch,
  and common failures.

- [Booting a PowerPC Mac from a USB stick](powermac-boot.md): writing the
  `macppc32` image, the Option-key picker and the Open Firmware prompt, the
  fan warning, and the slow Xzed session.

- [Booting a 68040 Macintosh from a BlueSCSI disk](mac68k-boot.md): the
  `mac68k` image on a BlueSCSI v2, installing Apple's disk driver with Apple
  HD SC Setup or Drive Setup, the monitor and memory settings, and the
  loader's messages.

- [Programming a Keiland application](keiland-programming.md): the
  application, its window and titlebar, the immediate mode user interface and
  the main loop, the widgets, the menus, and the desktop's other services.
