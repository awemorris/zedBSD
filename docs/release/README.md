# Releases

Status: reference; the documents that go with each release.

Each release of zedBSD comes with a guide to install and start it and a list
of the problems known at the time of the release. The release notes,
which list what the release contains, are published with the release on
GitHub.

## Kei/zedBSD 1.0.0 Beta 2

The release's own name (the system was called Kei then).

- [User guide](zedbsd-1.0.0-beta2-guide.md): writing the image to a USB
  drive, the firmware settings, the first login, Wi-Fi and the security
  notes.
- [Known issues](zedbsd-1.0.0-beta2-known-issues.md): problems you may meet
  and what to do about them.
- [Release notes](zedbsd-1.0.0-beta2.md): what the release contains, as
  published with the release on GitHub.
