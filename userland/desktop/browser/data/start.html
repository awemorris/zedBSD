Getting around

  • Click a link to follow it. Back, Forward and Reload are in the title bar.
  • Alt+Left and Alt+Right go back and forward; F5 reloads.
  • Ctrl+L edits the location; type a file path and press Enter.
  • The arrow keys, Page Up, Page Down, Space, Home and End scroll.
  • Ctrl+W or Ctrl+Q closes the window.

Today and tomorrow

Local files open today. Networking, images, JavaScript in pages and more CSS arrive step by step.

The JavaScript engine already runs scripts on its own: browser --js FILE.js.
