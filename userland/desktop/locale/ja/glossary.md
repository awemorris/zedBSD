# Japanese glossary of Keiland

Status: reference; the words the Japanese catalogs (`*.tr` here) use, so
that the desktop and its applications say one thing one way.

A translator checks a new text against this list before adding it, and adds
a word here when a catalog uses it for the first time.
`tools/i18n/tr.py check` checks the catalogs' form; this list is checked
by review.

## Style

| Rule | Example |
| --- | --- |
| Polite form (です・ます) for sentences; a plain noun phrase for names, labels and buttons | 「変更はすぐに反映されます。」 / 「画面をロック」 |
| A summary under a heading ends with 「。」 when it is a sentence, and without one when it is a noun phrase | 「有線の接続とそのアドレス。」 |
| Words still under way end with three ASCII dots, as the English | 「接続しています...」 |
| Parentheses are full width; a colon is ASCII with a space after it | 「なし（英語）」 / 「Wiseview: すべてのウインドウを一覧」 |
| A space between Japanese and Latin letters or digits | 「Wi-Fi に接続」 / 「PIN は 6 桁です。」 |
| A person's name is followed by 「さん」 | 「{1} さん、おはようございます」 |
| Keep each `{1}` place; move it to where Japanese puts it | 「{1} に接続しています...」 |

## Names that stay in English

Kei, zedBSD, Keiland, App Home, Wiseview, Wi-Fi, Bluetooth, VPN, DNS, MAC,
MTU, IPv4, PIN, SKK, and key names (Super, Alt, Tab, Ctrl, Space, Enter,
Esc).
